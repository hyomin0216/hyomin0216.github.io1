디스코드 사용법

디스코드 안 켜질 때·오류·렉 해결법: 무한 로딩부터 재설치까지

디스코드(디코)가 안 켜지거나 무한 로딩·회색 화면·업데이트 실패·렉이 생길 때 순서대로 해볼 해결법을 정리했어요. 작업 관리자 종료, 캐시 삭제, 깨끗한 재설치, 서버 장애 확인 방법까지 담았어요.

2026년 11월 3일 작성· 약 3분· Rito0223

핵심 요약

  • 먼저 discordstatus.com에서 디스코드 서버 장애인지 확인하세요. 장애라면 기다리는 것 말고는 방법이 없어요.
  • PC라면 작업 관리자에서 Discord를 모두 종료한 뒤 다시 켜는 것만으로 대부분 해결돼요.
  • 그래도 안 되면 %appdata%\discord 의 Cache·Code Cache·GPUCache 폴더를 지우세요. 로그인 정보는 그대로예요.
  • 마지막 방법은 %appdata%\discord 와 %localappdata%\Discord 를 지운 뒤 깨끗하게 재설치하는 거예요.

디스코드를 눌렀는데 아무 반응이 없거나, 로고만 돌다가 멈추거나, 업데이트에서 계속 실패하는 경우가 있어요. 원인은 다양하지만 해결 순서는 거의 같아요. 쉬운 것부터 하나씩 해 보세요.

디스코드가 안 켜질 때 가장 먼저 할 일은?

디스코드 자체 장애인지 먼저 확인하세요. 공식 상태 페이지 discordstatus.com에 문제가 표시되어 있다면 내 컴퓨터 문제가 아니에요. 이때는 기다리거나 휴대폰 앱·웹 버전으로 접속해 보세요.

Windows에서 디스코드가 안 켜질 때 해결 순서

1. 작업 관리자에서 완전히 종료하고 다시 켜기

  1. Ctrl + Shift + Esc 로 작업 관리자를 엽니다.
  2. Discord 항목을 모두 골라 작업 끝내기를 누릅니다. (여러 개일 수 있어요)
  3. 디스코드를 다시 실행합니다.

창을 닫아도 디스코드는 트레이(오른쪽 아래)에서 계속 돌아가요. 이 상태가 꼬이면 새로 켜도 반응이 없어요.

2. 관리자 권한으로 실행하기

디스코드 아이콘을 우클릭 → 관리자 권한으로 실행해 보세요. 업데이트 파일을 쓸 권한이 없어 멈춰 있는 경우에 효과가 있어요.

3. 캐시 폴더 지우기

  1. 작업 관리자에서 디스코드를 완전히 종료합니다.
  2. Win + R 을 누르고 %appdata%\discord 를 입력해 엽니다.
  3. Cache, Code Cache, GPUCache 폴더를 삭제합니다.
  4. 디스코드를 다시 켭니다.

캐시를 지워도 계정·서버·메시지는 그대로예요. 디스코드 서버에 저장돼 있기 때문이에요. 다시 로그인하라고 나올 수는 있어요.

4. 깨끗하게 재설치하기

  1. 설정 → 앱에서 Discord를 제거합니다.
  2. %appdata%\discord 폴더와 %localappdata%\Discord 폴더를 통째로 삭제합니다.
  3. 공식 사이트 discord.com/download 에서 새로 받아 설치합니다.

그냥 지우고 다시 깔면 남아 있는 폴더 때문에 같은 문제가 반복될 수 있어요. 2번 단계까지 해야 “깨끗한 재설치”예요.

업데이트 실패(Update Failed)가 반복될 때는?

  • 백신·방화벽이 디스코드 업데이트를 막고 있을 수 있어요. 잠시 끄거나 디스코드를 예외로 추가해 보세요.
  • VPN·프록시를 쓰고 있다면 끄고 다시 시도하세요.
  • 디스크 용량이 부족하지 않은지 확인하세요.
  • 그래도 안 되면 위의 깨끗한 재설치를 하세요.

디스코드 렉이 심하거나 화면이 깨질 때는?

  • 하드웨어 가속: 사용자 설정 → 고급에서 하드웨어 가속을 끄거나 켜서 비교해 보세요. 그래픽카드에 따라 결과가 달라요.
  • 게임 오버레이 끄기: 게임 중 렉이 생긴다면 사용자 설정 → 게임 오버레이를 꺼 보세요.
  • 움직이는 효과 줄이기: 접근성 → 동작 줄이기, GIF 자동 재생 끄기를 켜면 가벼워져요.
  • 음성이 끊기는 렉이라면 마이크·소리 해결법의 음성 설정 초기화를 해 보세요.

휴대폰에서 디스코드가 안 켜질 때는?

  1. 앱을 완전히 종료(최근 앱 목록에서 위로 밀기)한 뒤 다시 엽니다.
  2. 앱스토어·구글 플레이에서 업데이트가 있는지 확인합니다.
  3. 안드로이드는 설정 → 앱 → Discord → 저장공간 → 캐시 삭제를 해 보세요.
  4. 그래도 안 되면 앱을 지우고 다시 설치하세요.

서버가 갑자기 엉망이 돼서 디스코드가 이상한 것처럼 보인다면, 앱 문제가 아니라 서버 테러일 수도 있어요. 서버 테러 막는 보안 설정을 확인해 보세요.

자주 묻는 질문

디스코드가 안 켜질 때 가장 먼저 뭘 해야 하나요?

discordstatus.com에서 디스코드 서버 장애인지 확인하고, 장애가 아니라면 작업 관리자에서 Discord를 모두 종료한 뒤 다시 켜 보세요.

디스코드 캐시를 지우면 대화 내용이 사라지나요?

아니요. 메시지와 서버는 디스코드 서버에 저장돼 있어서 캐시를 지워도 그대로예요. 다시 로그인해야 할 수는 있어요.

디스코드 캐시 폴더는 어디 있나요?

Windows에서 Win + R을 누르고 %appdata%\discord 를 입력하면 열려요. 그 안의 Cache, Code Cache, GPUCache 폴더를 지우면 돼요.

디스코드 업데이트 실패가 계속 떠요.

백신·방화벽·VPN을 잠시 끄고 다시 시도해 보세요. 그래도 안 되면 %appdata%\discord 와 %localappdata%\Discord 를 지우고 다시 설치하세요.

디스코드 렉은 어떻게 줄이나요?

하드웨어 가속 설정을 바꿔 보고, 게임 오버레이와 GIF 자동 재생을 끄면 가벼워져요.
