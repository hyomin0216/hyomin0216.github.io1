디스코드 사용법

디스코드 메시지 수정·삭제·답장·고정·검색하는 법 (PC·모바일)

디스코드(디코) 메시지를 다루는 기본 기능을 모았어요. 메시지 수정과 삭제, 답장 달기, 메시지 고정, 옛날 메시지 검색하는 법과 검색 필터, 다른 사람 메시지를 지울 수 있는 권한까지 PC·모바일로 나눠 적었어요.

2026년 11월 22일 작성· 리토(Rito0223)

핵심 요약

  • PC는 메시지에 마우스를 올리면 수정·답장 버튼이 뜨고, … 메뉴에 삭제·고정이 있어요. 휴대폰은 메시지를 길게 눌러요.
  • 방금 보낸 메시지는 PC에서 키보드 위쪽 화살표(↑)를 누르면 바로 고칠 수 있어요.
  • 휴대폰에서는 메시지를 옆으로 밀면 바로 답장이 돼요.
  • 옛날 메시지는 오른쪽 위 검색창에서 찾고, from: in: has: 같은 필터를 붙이면 훨씬 빨리 찾아요.

오타 난 메시지를 고치거나, 잘못 보낸 메시지를 지우거나, 중요한 공지를 맨 위에 걸어 두는 건 디스코드에서 매일 쓰는 기능이에요. 그런데 버튼이 숨어 있어서 모르고 지나치는 분이 많아요.

디스코드 메시지는 어떻게 수정하나요?

  • PC: 내 메시지에 마우스를 올리고 연필 모양(수정)을 눌러요
  • PC 빠른 방법: 채팅창이 비어 있을 때 키보드 ↑를 누르면 방금 보낸 메시지를 바로 고칠 수 있어요
  • 휴대폰: 내 메시지를 길게 누르고 메시지 수정을 눌러요

고친 메시지 옆에는 ‘(수정됨)’ 표시가 붙어요. 고치기 전 내용은 다른 사람에게 보이지 않아요.

디스코드 메시지는 어떻게 삭제하나요?

  • PC: 메시지에 마우스를 올리고 … 메뉴 → 메시지 삭제
  • PC 빠른 방법: Shift 키를 누른 채 휴지통 버튼을 누르면 확인 창 없이 바로 지워져요
  • 휴대폰: 메시지를 길게 누르고 메시지 삭제

지운 메시지는 되돌릴 수 없어요. 그리고 지우기 전에 다른 사람이 이미 봤거나 캡처했을 수 있으니, 중요한 정보는 처음부터 조심해서 보내세요.

다른 사람 메시지도 지울 수 있나요?

서버에서 메시지 관리 권한이 있는 역할만 다른 사람 메시지를 지울 수 있어요. DM에서는 상대 메시지를 지울 수 없어요. 도배나 광고를 자주 지워야 한다면 운영진 역할에 메시지 관리 권한을 주세요. (디스코드 역할·권한 설정)

답장은 어떻게 다나요?

  • PC: 메시지에 마우스를 올리고 화살표 모양(답장)을 눌러요
  • 휴대폰: 메시지를 옆으로 밀면 바로 답장이 돼요. 길게 눌러서 답장을 골라도 돼요

답장하면 원래 메시지가 위에 작게 붙어서, 대화가 빠르게 흘러가는 채널에서도 누구한테 하는 말인지 알 수 있어요. 답장할 때 상대에게 알림을 보낼지는 입력창 위 @켜짐/꺼짐 버튼으로 정할 수 있어요.

메시지 고정은 어떻게 하나요?

  • PC: 메시지 … 메뉴 → 메시지 고정
  • 휴대폰: 메시지를 길게 누르고 고정
  • 고정 메시지 보기: 채널 위쪽 핀 모양 아이콘을 누르면 모아서 볼 수 있어요

서버에서는 고정 권한이 있는 사람만 고정할 수 있고, DM에서는 둘 다 고정할 수 있어요. 규칙, 자주 묻는 질문, 링크 모음처럼 계속 봐야 하는 걸 고정해 두면 같은 질문이 줄어요.

옛날 메시지는 어떻게 찾나요?

PC는 오른쪽 위 검색창, 휴대폰은 채널이나 DM 위쪽 돋보기를 눌러요. 단어만 넣어도 되지만, 아래 필터를 붙이면 훨씬 빨라요.

  • from: 특정 사람이 보낸 메시지만
  • in: 특정 채널에서만
  • has: 링크, 사진, 파일 등이 들어간 메시지만 (예: has:link, has:image, has:file)
  • mentions: 특정 사람을 부른 메시지만
  • before: after: 날짜 전후로 좁히기

예를 들어 “친구가 예전에 보낸 링크”를 찾고 싶다면 검색창에 from: 을 쓰고 친구를 고른 뒤 has:link 를 붙이면 돼요.

메시지를 더 보기 좋게 쓰고 싶다면

굵게, 스포일러, 코드블록, 큰 글씨 같은 꾸미기는 디스코드 채팅 꾸미기에, 사진과 파일 보내는 법은 디스코드 사진·파일 보내는 법에 정리해 뒀어요. 공지·규칙 채널을 깔끔하게 정리한 서버가 필요하다면 디스코드 서버제작도 있어요.

자주 묻는 질문

디스코드 메시지는 어떻게 수정해요?

PC는 내 메시지에 마우스를 올리고 연필 버튼을 누르거나, 채팅창이 비어 있을 때 ↑ 키를 누르면 돼요. 휴대폰은 메시지를 길게 누르고 메시지 수정을 골라요.

디스코드 메시지를 지우면 상대도 못 보나요?

지우면 채팅에서 사라져서 이후엔 아무도 못 봐요. 다만 지우기 전에 이미 봤거나 캡처했을 수는 있어요. 지운 메시지는 되돌릴 수 없어요.

다른 사람 메시지를 지울 수 있어요?

서버에서 메시지 관리 권한이 있는 역할만 지울 수 있어요. DM에서는 상대 메시지를 지울 수 없어요.

디스코드 메시지 고정은 어떻게 해요?

PC는 메시지 … 메뉴에서 메시지 고정, 휴대폰은 메시지를 길게 눌러 고정을 고르면 돼요. 고정된 메시지는 채널 위쪽 핀 아이콘에서 볼 수 있어요.

옛날 디스코드 메시지는 어떻게 찾아요?

PC는 오른쪽 위 검색창, 휴대폰은 돋보기를 눌러 검색해요. from:, in:, has:link 같은 필터를 붙이면 더 빨리 찾을 수 있어요.
