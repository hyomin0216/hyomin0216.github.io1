디스코드 역할 만들기와 권한 설정: 색깔·순서·채널별 권한 한 번에 정리

디스코드(디코) 역할 만드는 법, 역할 색깔과 따로 표시하기, 역할 순서가 중요한 이유, 위험한 권한, 채널별 권한 설정, 역할 아이콘(부스트 레벨 2)까지 적었어요.

2026년 11월 11일 작성· Rito0223

핵심 요약

  • 역할은 서버 설정 → 역할 → 역할 만들기에서 만들고, 이름·색깔·권한을 정해요.
  • 역할 목록에서 위에 있을수록 힘이 세요. 나보다 위에 있는 역할은 관리할 수 없어서, 봇 역할도 위쪽에 둬야 해요.
  • 관리자, 서버 관리, 역할 관리, 멤버 추방·차단 권한은 믿을 수 있는 운영진에게만 주세요.
  • 채널마다 볼 수 있는 사람을 다르게 하려면 채널 편집 → 권한에서 역할별로 허용(✓)·거부(✗)를 걸어요.

서버 운영에서 제일 많이 꼬이는 게 역할이랑 권한이에요. “분명히 권한 줬는데 왜 안 보여요?”, “봇이 역할을 못 줘요” 같은 문제는 거의 다 여기서 생겨요.

역할 만드는 법부터, 순서가 왜 중요한지, 채널별로 권한을 거는 법까지 차례로 적어 볼게요.

디스코드 역할은 어떻게 만드나요?

  1. 서버 이름을 눌러 서버 설정 → 역할로 들어가요.
  2. 역할 만들기를 눌러요.
  3. 표시 탭에서 이름과 색깔을 정해요.
  4. 권한 탭에서 이 역할이 할 수 있는 일을 켜고 저장해요.

멤버에게 역할을 주려면 멤버 목록에서 이름을 우클릭(휴대폰은 길게 누르기)하고 역할에서 체크하면 돼요.

같이 켜 두면 좋은 설정

  • 역할 멤버를 따로 표시: 오른쪽 멤버 목록에서 이 역할끼리 묶여서 보여요. 운영진 역할에 켜 두면 누가 운영진인지 바로 보여요
  • 누구나 @멘션 허용: 켜면 누구나 이 역할을 한 번에 부를 수 있어요. 큰 역할은 꺼 두는 게 좋아요

역할 순서는 왜 중요한가요?

역할 목록은 위에 있을수록 힘이 세요. 그리고 내가 가진 가장 높은 역할보다 아래에 있는 역할만 관리할 수 있어요.

  • 봇이 역할을 못 줄 때: 봇 역할이 주려는 역할보다 아래에 있어서 그래요. 봇 역할을 위로 끌어 올리세요
  • 운영진이 다른 운영진을 못 건드릴 때: 같은 높이거나 위에 있는 역할은 관리가 안 돼요
  • 이름 색이 이상할 때: 색깔은 가진 역할 중 가장 위에 있는 역할 색으로 보여요

순서는 서버 설정 → 역할에서 끌어다 놓으면 바뀌어요. 보통 서버 주인 바로 아래 운영진, 그 아래 봇, 그 아래 일반 멤버 순서로 둬요.

어떤 권한은 조심해야 하나요?

아래 권한은 서버를 통째로 망가뜨릴 수 있어서, 믿을 수 있는 사람에게만 주세요.

  • 관리자: 모든 권한을 다 가져요. 채널 권한도 무시해요
  • 서버 관리: 서버 이름·설정을 바꾸고 봇을 넣을 수 있어요
  • 역할 관리: 자기보다 아래 역할을 마음대로 바꿀 수 있어요
  • 채널 관리: 채널을 만들고 지울 수 있어요
  • 멤버 추방·차단: 사람을 내보낼 수 있어요
  • @everyone 멘션: 서버 전체에 알림을 보낼 수 있어요

서버 테러는 대부분 이런 권한을 가진 계정이 털려서 생겨요. 운영진에게 관리자 권한을 통째로 주기보다 필요한 권한만 골라 주고, 운영진 전원 2단계 인증을 켜 두세요. (서버 테러 막는 보안 설정)

@everyone 역할은 뭔가요?

서버에 있는 모든 사람이 자동으로 가진 기본 역할이에요. 지울 수 없고, 여기서 정한 권한이 모든 사람의 기본값이 돼요. 그래서 @everyone 권한은 최소한으로 두고, 필요한 권한은 다른 역할에 따로 주는 게 안전해요.

채널마다 권한을 다르게 하려면?

  1. 채널 이름 옆 톱니바퀴(채널 편집)를 누르고 권한으로 들어가요.
  2. 역할 또는 멤버 추가로 권한을 바꿀 역할을 골라요.
  3. 권한마다 ✓(허용), /(기본값 따르기), ✗(거부) 중에 골라요.

예를 들어 공지 채널은 @everyone의 ‘메시지 보내기’를 ✗로, 운영진 역할만 ✓로 두면 운영진만 글을 쓸 수 있는 공지방이 돼요. 비공개 채널 만드는 법은 디스코드 채널 만들기에 있어요.

권한을 걸고 나서 잘 됐는지 확인하려면 서버 설정 → 역할에서 역할을 고르고 역할로 서버 보기를 눌러 보세요. 그 역할을 가진 사람 눈에 서버가 어떻게 보이는지 그대로 볼 수 있어요.

역할 이름 옆에 아이콘을 넣을 수 있나요?

서버 부스트 레벨 2부터 돼요. 서버 설정 → 역할 → 역할 고르기 → 표시에서 역할 아이콘에 64×64 크기, 256KB 이하 이미지를 올리면 채팅에서 이름 옆에 아이콘이 붙어요. 움직이는 이미지는 안 되고, 아직 PC에서만 설정할 수 있어요.

부스트 레벨을 올리는 방법은 서버 부스트 하는 법에, 부스트 문의는 디스코드 서버부스트에 있어요.

역할은 몇 개까지 만들 수 있나요?

서버 하나에 최대 250개까지 만들 수 있어요. 많아 보여도 색깔 역할, 게임 역할, 알림 역할을 다 만들다 보면 금방 늘어나니 처음부터 꼭 필요한 것만 만드는 게 좋아요.

역할 등급 설계부터 봇으로 역할 자동 지급까지 한 번에 맞추고 싶다면 디스코드 서버제작으로 맡기셔도 돼요.

자주 묻는 질문

디스코드 역할은 어떻게 만들어요?

서버 설정 → 역할 → 역할 만들기에서 이름·색깔·권한을 정하고 저장하면 돼요. 멤버에게는 멤버 목록에서 이름을 우클릭해 역할을 체크하면 돼요.

봇이 역할을 못 줘요.

봇 역할이 주려는 역할보다 아래에 있어서 그래요. 서버 설정 → 역할에서 봇 역할을 위로 끌어 올리세요.

특정 역할만 채널을 보게 하려면 어떻게 해요?

채널 편집 → 권한에서 @everyone의 '채널 보기'를 거부(✗)로, 보여 줄 역할의 '채널 보기'를 허용(✓)으로 바꾸면 돼요.

디스코드 역할 아이콘은 어떻게 넣어요?

서버 부스트 레벨 2부터 서버 설정 → 역할 → 표시에서 64×64, 256KB 이하 이미지를 올릴 수 있어요. 아직 PC에서만 설정할 수 있어요.

디스코드 역할은 몇 개까지 만들 수 있어요?

서버 하나에 최대 250개까지 만들 수 있어요.
