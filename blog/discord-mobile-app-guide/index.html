디스코드 사용법

디스코드 모바일 사용법: 휴대폰 앱 화면 구성, 통화·알림, PC와 같이 쓰는 법

디스코드(디코)를 휴대폰으로 쓰는 법을 정리했어요. 앱 설치와 로그인, 새로 바뀐 아래쪽 메뉴, 서버·DM 오가는 법, 통화와 화면공유, 알림 설정, 데이터 아끼는 법, PC와 같이 쓸 때 알아둘 것까지 담았어요.

2026년 11월 22일 작성· Rito0223

핵심 요약

  • 디스코드 앱은 App Store와 Google Play에서 “Discord”를 검색해서 받아요. PC와 같은 계정으로 로그인하면 서버와 대화가 그대로 보여요.
  • 요즘 앱은 화면 맨 아래에 내 프로필 사진·이름·상태가 있는 줄이 있어요. 누르면 프로필과 설정, 오른쪽 종 모양은 알림이에요.
  • 아래 줄을 왼쪽에서 오른쪽으로 쓸면 DM과 지금 보던 서버를 오갈 수 있어요.
  • 음성 채널을 누르면 바로 통화에 들어가고, 화면공유도 휴대폰에서 할 수 있어요.

디스코드는 PC로 쓰는 앱이라는 느낌이 강하지만, 요즘은 휴대폰으로만 쓰는 분도 정말 많아요. 그런데 앱 화면이 몇 번 바뀌면서 “설정이 어디 갔어요?”, “서버 목록이 안 보여요” 같은 질문도 늘었어요.

휴대폰에서 디스코드를 쓸 때 알아 두면 편한 것들을 차례로 적어 볼게요. 앱 버전에 따라 버튼 위치가 조금 다를 수 있어요.

디스코드 모바일 앱은 어디서 받나요?

  • 아이폰·아이패드: App Store에서 “Discord” 검색
  • 안드로이드: Google Play에서 “Discord” 검색

개발사가 Discord Inc.인지 꼭 확인하세요. 비슷한 이름의 가짜 앱이나 외부 설치 파일은 계정이 털릴 수 있어요.

PC에서 쓰던 계정 그대로 쓰기

같은 이메일과 비밀번호로 로그인하면 서버, 친구, 대화가 그대로 보여요. 반대로 휴대폰에 로그인돼 있다면 PC 로그인 화면의 QR코드를 휴대폰으로 찍어서 비밀번호 없이 PC에 로그인할 수도 있어요. (디스코드 웹 버전·로그인)

디스코드 모바일 화면은 어떻게 생겼나요?

요즘 앱은 화면 맨 아래에 내 프로필 사진, 이름, 상태가 보이는 줄이 항상 떠 있어요. 디스코드는 이걸 ‘You Bar’라고 불러요. 대부분의 메뉴가 여기서 시작해요.

  • 한 번 누르기: 내 프로필이 열려요. 프로필 편집, 상점, 퀘스트, 설정이 여기 있어요
  • 설정 들어가기: 프로필 화면 오른쪽 위 톱니바퀴를 눌러요. 아래 줄의 내 사진을 길게 누르면 바로 설정으로 가요
  • 알림 보기: 아래 줄 오른쪽 종 모양을 눌러요
  • DM ↔ 서버 오가기: 아래 줄을 왼쪽에서 오른쪽으로 쓸면 DM과 지금 보던 서버를 왔다 갔다 해요
  • 계정 메뉴: 아래 줄을 길게 누르면 계정 메뉴가 열려요. 여러 계정을 바꿔 가며 쓸 때 편해요

예전에 쓰던 아래쪽 탭 메뉴가 그대로 보인다면 앱이 옛 버전이에요. 스토어에서 업데이트하면 위와 같은 화면으로 바뀌어요.

휴대폰으로 통화와 화면공유는 어떻게 하나요?

  • 서버 통화: 음성 채널을 누르고 참가를 누르면 바로 연결돼요
  • DM 통화: 친구와의 DM을 열고 위쪽 전화 버튼을 눌러요. 영상통화는 카메라 버튼이에요
  • 화면공유: 통화 화면 아래 메뉴에서 화면 공유를 누르고 휴대폰 화면 녹화를 허용하면 돼요
  • 스피커·이어폰 전환: 통화 화면의 스피커 버튼으로 바꿀 수 있어요

화면공유를 할 땐 휴대폰 알림이 같이 보일 수 있으니 방해 금지 모드를 켜 두세요. 자세한 건 디스코드 화면공유 하는 법에 있어요. 마이크가 안 잡히면 휴대폰 설정에서 Discord 마이크 권한부터 확인하세요. (디스코드 마이크·소리 해결법)

휴대폰 알림은 어떻게 정리하나요?

휴대폰으로 쓰면 알림이 제일 신경 쓰여요. 서버 아이콘을 길게 눌러 알림 설정에서 ‘@멘션만’으로 바꾸면 훨씬 조용해져요. 알림이 아예 안 오면 휴대폰 설정 → 앱 → Discord에서 알림이 허용돼 있는지 보세요.

PC에서 디스코드를 쓰고 있을 땐 휴대폰 알림이 잠깐 미뤄졌다가 와요. 그래서 “휴대폰 알림이 늦게 와요”라는 경우도 많아요. 알림 설정은 디스코드 알림 끄기·켜기에 자세히 적어 뒀어요.

데이터와 배터리를 아끼려면?

  • 영상·화면공유 시청: 와이파이가 아닐 때 오래 보면 데이터를 많이 써요
  • GIF·스티커 자동 재생: 설정에서 GIF와 움직이는 스티커 자동 재생을 끄면 데이터와 배터리를 아낄 수 있어요
  • 안 쓰는 서버 정리: 활동 많은 서버가 많으면 알림과 동기화로 배터리가 더 닳아요. 안 보는 서버는 음소거하거나 나가세요

모바일에서 안 되거나 PC가 편한 것

  • 게임 오버레이: Windows PC 앱 전용이에요. (디스코드 오버레이)
  • 역할 아이콘 같은 일부 서버 설정: PC에서만 바꿀 수 있는 것도 있어요
  • 복잡한 권한 정리: 휴대폰에서도 되지만 화면이 좁아서 PC가 훨씬 편해요

휴대폰으로도 서버를 만들고 채널을 추가할 수 있어요. 처음 만든다면 디스코드 서버 만드는 법을 보시고, 휴대폰으로 하나하나 세팅하기 번거롭다면 디스코드 서버제작으로 맡기셔도 돼요.

자주 묻는 질문

디스코드 모바일 앱은 어디서 받아요?

아이폰은 App Store, 안드로이드는 Google Play에서 Discord를 검색해서 받으면 돼요. 개발사가 Discord Inc.인지 확인하세요.

디스코드 모바일에서 설정은 어디 있어요?

화면 맨 아래 내 프로필 줄을 누르고, 열린 프로필 화면 오른쪽 위 톱니바퀴를 누르면 돼요. 아래 줄의 내 사진을 길게 눌러도 바로 설정으로 가요.

모바일에서 DM과 서버는 어떻게 오가요?

화면 맨 아래 내 프로필 줄을 왼쪽에서 오른쪽으로 쓸면 DM과 지금 보던 서버를 오갈 수 있어요.

휴대폰으로 디스코드 통화가 돼요?

네. 음성 채널을 눌러 참가하거나, DM 위쪽 전화 버튼으로 통화할 수 있어요. 화면공유와 영상통화도 돼요.

PC와 휴대폰에서 동시에 로그인해도 되나요?

네. 같은 계정으로 여러 기기에 동시에 로그인해서 쓸 수 있어요. PC를 쓰는 중에는 휴대폰 알림이 조금 늦게 올 수 있어요.
