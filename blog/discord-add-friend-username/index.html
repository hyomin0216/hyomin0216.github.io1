디스코드 사용법

디스코드 친구 추가하는 법: 내 아이디(사용자명) 확인·변경과 친구 요청 안 될 때

디스코드(디코) 친구 추가하는 법을 PC·모바일로 적었어요. 내 아이디(사용자명) 확인하는 곳, 표시 이름과 차이, 아이디 바꾸는 법, 숫자 사용자 ID 복사하는 법, 친구 요청이 안 될 때 확인할 것까지 담았어요.

2026년 11월 17일 작성 · 2026년 11월 22일 수정· Rito0223

핵심 요약

  • 친구 추가는 친구 탭 → 친구 추가하기에서 상대 사용자명(아이디)을 정확히 입력하면 돼요.
  • 내 아이디는 왼쪽 아래 프로필을 누르면 보여요. 사용자명은 친구 추가에 쓰는 고유한 이름이고, 표시 이름은 화면에 보이는 별명이에요.
  • 사용자명은 사용자 설정 → 내 계정에서 바꿀 수 있어요. 영어 소문자, 숫자, 밑줄(_), 마침표(.)만 쓸 수 있어요.
  • 친구 요청이 안 되면 철자, 상대의 친구 요청 허용 설정, 차단 여부를 확인하세요.

“디코 아이디 뭐야?” 하고 물어보면 의외로 어디서 보는지 모르는 분이 많아요. 예전에는 이름 뒤에 #1234 같은 숫자가 붙었는데, 지금은 사용자명 하나로 바뀌어서 더 헷갈리죠.

내 아이디 확인하는 곳부터, 친구 추가하는 법, 요청이 안 될 때 확인할 것까지 적어 볼게요.

내 디스코드 아이디는 어디서 보나요?

  • PC·웹: 왼쪽 아래 내 프로필 사진을 누르면 이름 아래에 사용자명이 보여요
  • 휴대폰: 화면 아래쪽 내 프로필을 누르면 이름 아래에 보여요

여기서 사용자명을 눌러 바로 복사할 수 있어요. 친구한테 알려 줄 때는 이걸 보내면 돼요.

사용자명과 표시 이름은 뭐가 달라요?

  • 사용자명: 디스코드 전체에서 나 하나만 쓰는 고유한 아이디예요. 친구 추가할 때 이걸 입력해요
  • 표시 이름: 채팅에서 보이는 별명이에요. 한글이나 이모지도 되고, 다른 사람과 겹쳐도 돼요

그래서 친구가 “표시 이름으로 검색했는데 안 나와요”라고 하면, 사용자명을 다시 물어보면 대부분 해결돼요.

디스코드 친구 추가는 어떻게 하나요?

아이디로 추가하기

  1. PC는 왼쪽 위 디스코드 홈(DM 화면)에서 친구 탭으로 가요. 휴대폰은 아래쪽 메뉴에서 친구 화면으로 가요.
  2. 친구 추가하기를 눌러요.
  3. 상대 사용자명을 정확히 입력하고 친구 요청 보내기를 눌러요.
  4. 상대가 수락하면 친구 목록에 들어와요.

같은 서버에 있는 사람 추가하기

서버 멤버 목록이나 채팅에서 상대 이름을 누르면 프로필이 떠요. 여기서 친구 추가 버튼을 누르면 아이디를 몰라도 요청을 보낼 수 있어요.

디스코드 아이디는 어떻게 바꾸나요?

  1. 사용자 설정(톱니바퀴) → 내 계정으로 가요.
  2. 사용자명 옆 수정을 눌러요.
  3. 새 사용자명과 비밀번호를 입력하고 저장해요.
  • 쓸 수 있는 글자: 영어 소문자, 숫자, 밑줄(_), 마침표(.)
  • 길이: 2글자부터 32글자까지
  • 겹치면 안 돼요: 누가 이미 쓰고 있는 사용자명은 못 써요
  • 자주는 못 바꿔요: 짧은 시간에 여러 번 바꾸면 잠깐 막혀요

표시 이름은 사용자 설정 → 프로필에서 훨씬 자유롭게 바꿀 수 있어요. 프로필 꾸미는 법은 디스코드 프로필 꾸미기에 있어요.

숫자로 된 사용자 ID는 뭔가요?

디스코드는 모든 계정, 서버, 채널에 긴 숫자 ID를 붙여 둬요. 봇 설정이나 신고할 때 이 숫자를 달라고 하는 경우가 있어요.

  1. 사용자 설정 → 고급에서 개발자 모드를 켜요.
  2. ID가 필요한 사람 이름을 우클릭(휴대폰은 길게 누르기)해요.
  3. 사용자 ID 복사를 누르면 숫자가 복사돼요.

서버나 채널 ID도 같은 방법으로 복사할 수 있어요. 숫자 ID는 바뀌지 않아서, 사용자명을 바꿔도 그대로예요.

친구 요청이 안 될 때는?

  • 철자 확인: 사용자명은 한 글자만 틀려도 안 돼요. 마침표·밑줄 위치까지 확인하세요
  • 표시 이름을 넣었는지: 별명이 아니라 사용자명을 넣어야 해요
  • 상대가 요청을 막아 둔 경우: 사용자 설정 → 콘텐츠 및 소셜에서 친구 요청을 ‘같은 서버 멤버’나 ‘친구의 친구’만 받게 해 둘 수 있어요. 같은 서버에 들어가면 보낼 수 있어요
  • 차단된 경우: 서로 차단돼 있으면 요청이 안 가요
  • 친구 수가 꽉 찬 경우: 친구는 최대 1,000명까지예요

모르는 사람이 친구 요청을 보내고 “실수로 신고했다”, “무료 니트로 준다”며 링크를 보내면 거의 다 사기예요. (디스코드 계정 보안)

친구들이랑 모일 곳이 필요하다면

친구가 몇 명 모이면 DM 단체방보다 서버를 하나 만드는 게 훨씬 편해요. 채널을 나눌 수 있고, 음성방도 따로 둘 수 있거든요. 디스코드 서버 만드는 법을 보고 직접 만들거나, 디스코드 서버제작으로 맡기셔도 돼요.

자주 묻는 질문

디스코드 아이디는 어디서 봐요?

PC는 왼쪽 아래, 휴대폰은 화면 아래쪽 내 프로필을 누르면 이름 아래에 사용자명(아이디)이 보여요. 눌러서 복사할 수도 있어요.

디스코드 친구 추가는 어떻게 해요?

친구 탭에서 '친구 추가하기'를 누르고 상대 사용자명을 정확히 입력한 뒤 친구 요청을 보내면 돼요. 같은 서버에 있다면 상대 프로필의 친구 추가 버튼을 눌러도 돼요.

디스코드 아이디는 어떻게 바꿔요?

사용자 설정 → 내 계정에서 사용자명 옆 수정을 누르면 바꿀 수 있어요. 영어 소문자, 숫자, 밑줄, 마침표로 2~32글자만 쓸 수 있어요.

숫자로 된 디스코드 ID는 어떻게 복사해요?

사용자 설정 → 고급에서 개발자 모드를 켠 뒤, 이름을 우클릭하고 '사용자 ID 복사'를 누르면 돼요.

친구 요청이 안 보내져요.

사용자명 철자를 확인하고, 표시 이름이 아니라 사용자명을 넣었는지 보세요. 상대가 친구 요청을 같은 서버 멤버만 받게 해 뒀거나, 서로 차단돼 있거나, 친구가 1,000명이 꽉 찬 경우에도 안 돼요.

서버 세팅, 직접 하기 번거롭다면
