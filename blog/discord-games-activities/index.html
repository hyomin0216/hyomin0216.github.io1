디스코드 사용법

디스코드 게임 같이 하는 법: 액티비티로 통화하면서 미니게임 하기

디스코드(디코) 안에서 친구들과 바로 게임하는 액티비티 사용법을 적었어요. 음성 채널·DM 통화·채팅에서 액티비티 시작하는 법, 어떤 게임이 있는지, 안 보일 때 확인할 것, 게임하는 중 디스코드 활동 상태 보이게 하는 법까지 담았어요.

2026년 11월 17일 작성· 약 3분· Rito0223

핵심 요약

  • 디스코드에는 따로 설치 없이 통화하면서 같이 하는 미니게임, ‘액티비티’가 있어요.
  • 음성 채널이나 DM 통화에 들어가서 아래쪽 앱 실행(로켓 모양) 버튼을 누르고 게임을 고르면 시작돼요.
  • 채팅창의 앱 실행 버튼으로 시작하면, 다른 사람은 채팅에 뜬 참가 버튼으로 들어와요.
  • PC, 웹, 휴대폰에서 모두 할 수 있어요. 버튼이 안 보이면 앱 업데이트와 서버의 앱 사용 권한을 확인하세요.

디스코드는 원래 게임하면서 통화하려고 쓰는 앱이었는데, 이제는 디스코드 안에서 바로 게임을 할 수도 있어요. 통화방에 모여서 버튼 하나 누르면 그림 맞히기, 단어 게임, 미니 골프 같은 걸 다 같이 할 수 있어요.

이걸 ‘액티비티’라고 부르는데, 의외로 모르는 분이 많아서 정리해 볼게요.

디스코드 액티비티가 뭔가요?

디스코드 안에서 창으로 열리는 작은 게임이나 함께 쓰는 도구예요. 따로 게임을 깔 필요 없이, 같은 통화방이나 채팅방에 있는 사람들이 바로 같이 할 수 있어요.

  • 그림·단어 게임: 그림 그리고 맞히기, 단어 만들기 같은 파티 게임
  • 미니 스포츠: 미니 골프, 축구 같은 가벼운 대결 게임
  • 보드·카드 게임: 체스, 카드 게임 같은 턴제 게임
  • 함께 쓰는 도구: 화이트보드처럼 같이 그리고 쓰는 앱

목록은 디스코드가 자주 바꿔서, 앱 실행 버튼을 눌러 지금 있는 걸 보는 게 제일 정확해요.

음성 채널에서 액티비티는 어떻게 시작하나요?

  1. 서버의 음성 채널에 들어가요.
  2. 통화 화면 아래쪽 앱 실행 버튼(로켓 모양)을 눌러요.
  3. 하고 싶은 게임을 골라요. 처음 쓰는 앱이면 권한 승인 화면이 떠요.
  4. 같은 음성 채널에 있는 사람들은 화면에 뜬 액티비티에 바로 참가할 수 있어요.

DM 통화나 채팅에서도 되나요?

  • DM·그룹 통화: 통화를 시작하고 아래쪽 앱 실행 버튼을 누르면 서버랑 똑같이 시작돼요
  • 채팅방: 채팅 입력창 옆 앱 실행 버튼에서 게임을 고르고 실행을 누르면, 채팅에 액티비티 메시지가 올라와요. 다른 사람은 그 메시지의 참가 버튼을 누르면 돼요

채팅방에서 시작하는 방식은 통화하지 않고 턴제 게임을 느긋하게 할 때 좋아요.

액티비티 버튼이 안 보일 때는?

  • 앱 업데이트: 오래된 버전이면 버튼이 안 보일 수 있어요. 디스코드를 최신으로 업데이트하세요
  • 서버 권한: 서버에서 ‘앱 사용’이나 ‘액티비티 사용’ 권한이 꺼져 있으면 시작할 수 없어요. 관리자에게 확인하세요
  • 음성 채널에 들어갔는지: 통화 화면 아래 버튼이라 음성 채널에 먼저 들어가야 보여요
  • 연령 제한: 일부 게임은 연령 제한이 있어서 목록에 안 보일 수 있어요

서버 운영자라면 음성 채널 권한에서 액티비티 사용을 켜 둔 ‘게임방’을 따로 만들어 두세요. 멤버들이 모일 이유가 생겨서 서버가 훨씬 활발해져요. 권한 설정은 디스코드 역할·권한 설정에 있어요.

다른 게임 하면서 친구한테 보여 주려면?

롤이나 배그처럼 PC 게임을 할 때 프로필에 “OO 하는 중”이 뜨게 할 수 있어요. 사용자 설정 → 활동 개인정보 보호에서 활동 상태 공유를 켜 두면, 디스코드가 게임을 알아보고 프로필에 보여 줘요. 반대로 숨기고 싶으면 여기서 끄면 돼요.

게임하면서 화면을 보여 주고 싶다면 디스코드 화면공유 하는 법을, 게임 중에 통화 화면을 띄우고 싶다면 디스코드 오버레이 켜는 법을 참고하세요.

같이 게임할 서버가 필요하다면

게임 친구들이 모이는 클랜 서버는 파티 모집, 공략, 음성방이 잘 나뉘어 있어야 오래가요. 게임 서버 채널 구성 예시는 디스코드 채널 만들기에 있고, 구성부터 봇까지 한 번에 맡기고 싶다면 디스코드 서버제작도 있어요.

자주 묻는 질문

디스코드에서 게임을 바로 할 수 있어요?

네. 액티비티라는 기능으로 음성 채널, DM 통화, 채팅방에서 설치 없이 미니게임을 같이 할 수 있어요.

디스코드 액티비티는 어떻게 시작해요?

음성 채널이나 DM 통화에 들어가서 아래쪽 앱 실행(로켓 모양) 버튼을 누르고 게임을 고르면 돼요. 채팅방에서는 입력창 옆 앱 실행 버튼으로 시작할 수 있어요.

휴대폰으로도 디스코드 게임을 할 수 있어요?

네. 액티비티는 PC, 웹, 휴대폰 앱에서 모두 할 수 있어요.

액티비티 버튼이 안 보여요.

디스코드를 최신 버전으로 업데이트하고, 음성 채널에 들어갔는지, 서버에서 앱·액티비티 사용 권한이 켜져 있는지 확인하세요.

게임하는 중이라고 프로필에 뜨게 하려면요?

사용자 설정 → 활동 개인정보 보호에서 활동 상태 공유를 켜면 디스코드가 하고 있는 게임을 프로필에 보여 줘요.
