디스코드 사용법

디스코드 알림 끄기·켜기, 알림이 안 올 때 해결법 (PC·모바일)

디스코드(디코) 알림이 너무 많을 때 서버·채널별로 끄는 법, @everyone 알림만 막는 법, 반대로 알림이 안 올 때 PC·휴대폰에서 확인할 것을 적었어요.

2026년 11월 10일 작성· 약 2분· Rito0223

핵심 요약

  • 서버 이름 우클릭(휴대폰은 길게 누르기) → 알림 설정에서 서버 전체 알림을 ‘@멘션만’이나 ‘없음’으로 바꿀 수 있어요.
  • @everyone·@here 알림만 막고 싶으면 같은 화면에서 ‘@everyone과 @here 숨기기’를 켜요.
  • 채널 하나만 조용히 하고 싶으면 채널을 우클릭해서 그 채널만 알림을 바꾸면 돼요.
  • 알림이 안 오면 서버·채널 음소거, 휴대폰 앱 알림 권한, 방해 금지 상태부터 확인하세요.

서버를 몇 개만 들어가도 디스코드 알림이 하루 종일 울려요. 반대로 중요한 서버 알림만 안 와서 공지를 놓치는 경우도 있고요. 둘 다 알림 설정 몇 개만 손보면 해결돼요.

서버 알림을 통째로 줄이려면?

  1. PC는 서버 이름을 우클릭, 휴대폰은 서버 아이콘을 길게 눌러요.
  2. 알림 설정으로 들어가요.
  3. 서버 알림을 원하는 단계로 골라요.
  • 모든 메시지: 메시지 올라올 때마다 울려요. 작은 친구 서버에만 추천해요
  • @멘션만: 나를 부르거나 내 역할을 부를 때만 울려요. 대부분 서버는 이게 적당해요
  • 없음: 아예 안 울려요

같은 화면 위쪽 서버 음소거를 켜면 15분부터 ‘다시 켤 때까지’ 중에 기간을 골라서 서버를 통째로 조용하게 만들 수 있어요.

@everyone 알림만 막을 수 있나요?

돼요. 알림 설정 화면에서 아래 두 가지를 켜면 돼요.

  • @everyone과 @here 숨기기: 서버 전체를 부르는 알림이 안 와요
  • 모든 역할 @멘션 숨기기: 역할을 부르는 알림이 안 와요

이렇게 해 두면 나를 직접 부를 때만 알림이 와서 훨씬 조용해져요.

채널 하나만 알림을 끄려면?

채널 이름을 우클릭(휴대폰은 길게 누르기)하고 채널 음소거를 누르면 그 채널만 조용해져요. 알림 설정에 들어가서 그 채널만 ‘모든 메시지’로 바꿀 수도 있어요. 공지 채널만 모든 메시지로 받고 나머지는 멘션만 받는 식으로 쓰면 편해요.

서버 알림 설정 화면 아래 알림 재정의에서 채널·카테고리별 예외를 한눈에 보고 정리할 수 있어요.

디스코드 알림이 안 올 때는?

위에서부터 하나씩 확인해 보세요.

  • 서버나 채널이 음소거돼 있는지: 음소거된 채널은 이름이 흐리게 보여요. 서버를 음소거하면 휴대폰 알림도 같이 꺼져요
  • 내 상태가 방해 금지인지: 프로필 사진 옆이 빨간 원이면 방해 금지예요. 이 상태에서는 알림이 안 울려요
  • PC 알림 설정: 사용자 설정 → 알림에서 데스크톱 알림이 켜져 있는지 보세요
  • 휴대폰 앱 알림 권한: 휴대폰 설정 → 앱 → Discord → 알림이 허용돼 있는지 보세요
  • PC를 켜 두고 있는지: PC에서 디스코드를 쓰고 있으면 휴대폰 푸시를 잠깐 미뤄요. PC를 한동안 안 만지면 그때 휴대폰으로 와요
  • 배터리 절약 모드: 안드로이드는 배터리 최적화에서 Discord를 제외해야 알림이 늦지 않아요

서버 운영자라면 기본 알림을 바꿔 두세요

서버 설정 → 개요에서 기본 알림 설정을 ‘@멘션만’으로 바꿔 두면, 새로 들어온 멤버가 알림 폭탄에 질려서 나가는 걸 줄일 수 있어요. 대신 꼭 봐야 하는 건 공지 채널에 올리고 필요할 때만 @everyone을 쓰면 돼요. 채널 구성이 고민이라면 디스코드 서버 만드는 법도 같이 보세요.

자주 묻는 질문

디스코드 서버 알림은 어떻게 꺼요?

서버 이름을 우클릭(휴대폰은 길게 누르기)하고 알림 설정에서 서버 알림을 '@멘션만'이나 '없음'으로 바꾸거나, 서버 음소거를 켜면 돼요.

@everyone 알림만 끌 수 있어요?

네. 서버 알림 설정에서 '@everyone과 @here 숨기기'를 켜면 그 알림만 안 와요.

채널 하나만 알림을 끌 수 있어요?

채널 이름을 우클릭(휴대폰은 길게 누르기)하고 채널 음소거를 누르면 그 채널만 조용해져요.

디스코드 알림이 휴대폰으로 안 와요.

서버·채널 음소거, 방해 금지 상태, 휴대폰의 Discord 알림 권한을 확인하세요. PC에서 디스코드를 쓰는 중이면 휴대폰 알림이 잠깐 늦게 올 수 있어요.

서버를 음소거하면 휴대폰 알림도 꺼지나요?

네. 서버를 음소거하면 휴대폰 푸시 알림도 같이 꺼져요.
