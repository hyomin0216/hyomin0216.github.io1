디스코드 사용법

디스코드 마이크 안 될 때·소리 안 들릴 때 해결법 총정리

디스코드(디코) 마이크가 안 되거나 상대 소리가 안 들릴 때 순서대로 확인할 것을 정리했어요. 입력·출력 장치 선택, 입력 감도, 윈도우 마이크 권한, 음성 설정 초기화, 소음 억제까지 담았어요.

2026년 11월 3일 작성· 약 3분· Rito0223

핵심 요약

  • 먼저 사용자 설정 → 음성 및 비디오에서 입력 장치(마이크)와 출력 장치(스피커·헤드셋)가 맞게 골라져 있는지 확인하세요.
  • 마이크 테스트로 초록 막대가 움직이는지 보고, 안 움직이면 입력 감도를 자동으로 바꿔 보세요.
  • Windows는 설정 → 개인 정보 → 마이크에서 데스크톱 앱의 마이크 접근을 허용해야 해요.
  • 그래도 안 되면 음성 설정 맨 아래 음성 설정 초기화가 가장 빠른 해결책이에요.

디스코드 통화에서 “내 목소리가 안 들린대요”, “친구 소리가 안 들려요”는 가장 흔한 문제예요. 대부분은 장치 선택이나 권한 문제라서, 아래 순서대로 하나씩 확인하면 5분 안에 해결돼요.

디스코드 마이크가 안 될 때 가장 먼저 확인할 것은?

음소거 상태와 입력 장치부터 보세요. 의외로 이 두 가지가 원인인 경우가 가장 많아요.

  1. 왼쪽 아래 마이크 아이콘에 빨간 줄이 있다면 음소거예요. 눌러서 풀어 주세요.
  2. 음성 채널에서 서버가 나를 서버 음소거했다면 마이크 아이콘이 빨갛게 고정돼요. 관리자에게 풀어 달라고 하세요.
  3. 사용자 설정(톱니바퀴) → 음성 및 비디오 → 입력 장치에서 지금 쓰는 마이크를 직접 고르세요. “기본값”보다 장치 이름을 고르는 게 정확해요.
  4. 마이크 테스트 버튼을 누르고 말해 보세요. 막대가 움직이면 디스코드는 소리를 받고 있는 거예요.

마이크 테스트는 되는데 상대가 못 듣는다면?

  • 입력 감도: “입력 감도 자동 결정”이 꺼져 있으면 기준선보다 작은 목소리는 잘려요. 자동으로 켜거나 슬라이더를 왼쪽으로 내려 보세요.
  • 입력 모드: “눌러서 말하기”로 되어 있으면 정해진 키를 누를 때만 소리가 나가요. 평소처럼 쓰려면 음성 감지로 바꾸세요.
  • 소음 억제: 소음 억제(Krisp)가 목소리까지 지우는 경우가 있어요. 잠깐 꺼 보고 비교해 보세요.
  • 상대 쪽 문제: 상대가 나를 개인 음소거했거나, 내 사용자 음량을 0으로 줄였을 수 있어요.

Windows·Mac에서 마이크 권한은 어떻게 허용하나요?

운영체제확인할 곳
Windows 10·11설정 → 개인 정보 및 보안 → 마이크 → 마이크 액세스 켜기 + 데스크톱 앱의 마이크 접근 허용
macOS시스템 설정 → 개인정보 보호 및 보안 → 마이크 → Discord 켜기
웹 버전주소창 왼쪽 자물쇠 아이콘 → 마이크 허용
휴대폰휴대폰 설정 → 앱 → Discord → 권한 → 마이크 허용

디스코드에서 상대 소리가 안 들릴 때는?

  1. 왼쪽 아래 헤드셋 아이콘에 빨간 줄이 있으면 스피커 음소거예요. 풀어 주세요.
  2. 음성 및 비디오 → 출력 장치에서 지금 소리가 나야 하는 헤드셋·스피커를 고르세요.
  3. 출력 음량 슬라이더가 충분히 올라가 있는지 보세요.
  4. 특정 사람만 안 들리면 그 사람 이름을 우클릭 → 사용자 음량이 0이 아닌지 확인하세요.
  5. Windows 작업 표시줄 볼륨 믹서에서 Discord 음량이 꺼져 있지 않은지도 확인하세요.

다 해봐도 안 되면 어떻게 하나요?

  • 음성 설정 초기화: 음성 및 비디오 설정 맨 아래 음성 설정 초기화를 누르면 꼬인 설정이 한 번에 풀려요.
  • 오디오 서브시스템 바꾸기: 같은 화면의 오디오 서브시스템을 표준 ↔ 레거시로 바꿔 보세요. 일부 장치는 레거시에서만 잡혀요.
  • 다른 프로그램 종료: 다른 통화·녹음 프로그램이 마이크를 붙잡고 있으면 디스코드가 못 써요.
  • 선·포트 확인: USB 헤드셋은 다른 포트에 꽂아 보고, 3.5mm는 마이크 단자에 꽂혔는지 확인하세요.
  • 디스코드 재시작: 작업 표시줄 트레이 아이콘에서 완전히 종료한 뒤 다시 켜 보세요. 앱이 안 켜진다면 디스코드 안 켜질 때 해결법을 보세요.

통화방 관리가 고민이라면, 누가 언제 들어오고 나갔는지 남기는 통화방 로그를 서버에 설정해 두면 편해요. 디스코드 서버제작에서 로그 세팅까지 같이 맡길 수 있어요.

자주 묻는 질문

디스코드 마이크 테스트는 어디서 하나요?

사용자 설정(톱니바퀴) → 음성 및 비디오에서 '마이크 테스트' 버튼을 누르고 말하면 돼요. 막대가 움직이면 마이크가 잡히고 있는 거예요.

디스코드에서 내 목소리가 안 들린대요.

음소거 여부, 입력 장치 선택, 입력 감도, 입력 모드(눌러서 말하기)를 순서대로 확인하세요. Windows라면 마이크 개인 정보 권한도 허용돼 있어야 해요.

디스코드에서 다른 사람 소리가 안 들려요.

헤드셋 음소거 여부와 출력 장치 선택을 확인하세요. 특정 사람만 안 들리면 그 사람의 사용자 음량이 0인지 확인해 보세요.

디스코드 음성 설정 초기화는 어디 있나요?

사용자 설정 → 음성 및 비디오 화면 맨 아래에 '음성 설정 초기화' 버튼이 있어요.

소음 억제를 켜면 목소리가 끊겨요.

소음 억제가 목소리를 잡음으로 착각하는 경우예요. 소음 억제를 끄거나, 입력 감도를 조절해 보세요.
