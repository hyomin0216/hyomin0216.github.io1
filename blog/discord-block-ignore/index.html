디스코드 사용법

디스코드 차단하는 법과 차단하면 생기는 일, 무시하기와 차이

디스코드(디코)에서 사람을 차단하는 법(PC·모바일), 차단하면 상대에게 어떻게 보이는지, 차단 풀기, 상대가 모르게 거리를 두는 ‘무시하기’와 음소거 차이, 서버 운영자가 할 수 있는 조치까지 적었어요.

2026년 11월 25일 작성· Rito0223

핵심 요약

  • 상대 프로필을 열고 … 메뉴에서 차단을 누르면 돼요. 휴대폰도 프로필 오른쪽 위 … 메뉴에 있어요.
  • 차단하면 친구가 끊기고, 상대는 나에게 DM과 친구 요청을 보낼 수 없어요.
  • 같은 서버에서는 상대 메시지가 ‘차단된 메시지’로 접혀 보여요. 서버에서 내보내는 건 아니에요.
  • 상대가 모르게 거리만 두고 싶다면 ‘무시하기’가 있어요. 친구는 유지되고 상대 메시지와 알림만 숨겨져요.

디스코드를 하다 보면 계속 DM을 보내거나 시비를 거는 사람이 있을 때가 있어요. 그럴 때 쓰는 게 차단인데, 차단하면 상대가 아는지, 서버에서는 어떻게 되는지 헷갈려요.

차단하는 법과 차단하면 생기는 일, 그리고 차단보다 조용한 ‘무시하기’까지 정리해 볼게요.

디스코드 차단은 어떻게 하나요?

  • PC·웹: 상대 이름이나 프로필 사진을 눌러 프로필을 열고 … 메뉴 → 차단
  • 휴대폰: 상대 프로필 사진을 눌러 프로필을 열고 오른쪽 위 … → 차단
  • 어디서든: 서버 멤버 목록, 친구 목록, DM 어디에서 프로필을 열어도 돼요

차단하면 어떻게 되나요?

  • 친구 끊김: 친구였다면 친구 목록에서 빠져요
  • DM 막힘: 상대는 나에게 DM을 보낼 수 없어요
  • 친구 요청 막힘: 상대가 다시 친구 요청을 보낼 수 없어요
  • 같은 서버: 상대가 서버에 쓴 메시지는 ‘차단된 메시지’로 접혀 보이고, 눌러야 내용이 보여요
  • 서버에서는 그대로: 차단은 나한테만 적용돼요. 상대가 서버에서 나가지는 않아요

차단했다고 디스코드가 상대에게 알려 주지는 않아요. 하지만 DM이 안 가거나, 내 메시지에 반응을 못 다는 걸 보고 상대가 눈치챌 수는 있어요.

차단은 어떻게 풀어요?

상대 프로필의 … 메뉴에서 차단 해제를 누르면 돼요. 휴대폰은 설정 → 콘텐츠 및 소셜에서 차단한 계정 목록을 보고 풀 수도 있어요. 차단을 풀어도 친구는 자동으로 다시 맺어지지 않아서, 필요하면 친구 요청을 다시 보내야 해요.

상대가 모르게 거리를 두고 싶다면? 무시하기

차단은 너무 세게 느껴질 때 쓰는 게 무시하기예요. 친구 관계는 그대로 두고, 상대 쪽 소식만 내 화면에서 숨겨요.

  • 상대 메시지: 숨겨지고, ‘보기’를 눌러야 보여요
  • 알림: 상대가 보내는 메시지 알림이 안 와요
  • 상대에게는: 알림이 가지 않고, 상대는 평소처럼 메시지를 보낼 수 있어요
  • 친구: 끊기지 않아요

무시하기도 상대 프로필 사진을 우클릭(휴대폰은 프로필 → …)해서 무시하기를 누르면 돼요. 무시한 사람 목록에서 언제든 다시 풀 수 있어요.

음소거는 또 뭐가 달라요?

DM이나 서버, 채널을 음소거하면 알림만 안 울려요. 메시지는 그대로 보여요. 단톡방처럼 시끄러운 대화를 잠깐 조용히 할 때 쓰는 기능이에요. (디스코드 알림 설정)

괴롭힘이나 사기라면 신고도 같이 하세요

차단은 내 화면에서만 막는 거라, 상대가 다른 사람에게 같은 짓을 하는 건 못 막아요. 욕설, 괴롭힘, 사기 링크라면 메시지 메뉴의 신고하기로 디스코드에 신고하세요. 신고할 때 상대 사용자 ID가 필요하면 디스코드 개발자 모드를 켜고 복사하면 돼요.

서버 운영자라면

서버에서 문제를 일으키는 사람은 차단이 아니라 서버 조치를 써야 해요. 멤버 이름을 우클릭하면 타임아웃(일정 시간 채팅·음성 금지), 추방, 차단(밴)을 할 수 있어요. 테러나 도배를 미리 막는 설정은 서버 테러 막는 보안 설정에 정리해 뒀어요.

자주 묻는 질문

디스코드 차단은 어떻게 해요?

상대 프로필을 열고 … 메뉴에서 차단을 누르면 돼요. 휴대폰은 프로필 오른쪽 위 … 메뉴에 있어요.

디스코드에서 차단하면 상대가 알아요?

디스코드가 알림을 보내지는 않아요. 하지만 DM이 안 가거나 반응을 못 다는 걸 보고 눈치챌 수는 있어요.

차단하면 같은 서버에서는 어떻게 돼요?

상대 메시지가 '차단된 메시지'로 접혀 보여요. 상대가 서버에서 나가는 건 아니에요.

디스코드 차단은 어떻게 풀어요?

상대 프로필 … 메뉴에서 차단 해제를 누르거나, 휴대폰 설정 → 콘텐츠 및 소셜의 차단 목록에서 풀 수 있어요. 친구는 다시 요청해야 해요.

무시하기와 차단은 뭐가 달라요?

무시하기는 친구를 유지한 채 상대 메시지와 알림만 숨기고, 상대에게 알리지 않아요. 차단은 친구가 끊기고 DM과 친구 요청이 막혀요.
