니트로

디스코드 니트로 선물하기·받기, 구독 해지와 환불 방법 (PC·모바일)

디스코드(디코) 니트로를 친구한테 선물하는 법과 받는 법, 니트로 구독 해지(취소) 방법, 환불 기준(구매 후 5일·1회)까지 PC·모바일로 나눠서 적었어요. 선물 링크를 엉뚱한 사람이 가져가지 않게 보내는 요령도 있어요.

2026년 11월 4일 작성· 약 3분· Rito0223

핵심 요약

  • 니트로 선물은 채팅 입력창 옆에 있는 선물(🎁) 아이콘을 눌러서 요금제를 고르고 결제하면 돼요.
  • 채널이나 단체방에 올린 선물 링크는 먼저 누르는 사람이 가져가요. 한 사람한테 줄 거면 꼭 1:1 DM으로 보내세요.
  • 해지는 사용자 설정 → 구독 → 취소예요. 해지해도 이번에 결제한 기간이 끝날 때까지는 혜택이 그대로 남아요.
  • 환불은 보통 구매 후 5일 안에, 니트로는 딱 한 번만 돼요. 아이폰으로 결제했다면 애플 쪽에 요청해야 해요.

친구 생일에 니트로를 선물하고 싶은데 버튼이 어디 있는지 모르겠다는 분도 많고, 반대로 구독을 끊고 싶은데 메뉴가 안 보인다는 분도 많아요. 선물하는 법부터 받는 법, 해지, 환불까지 순서대로 적어 볼게요.

디스코드 니트로는 어떻게 선물하나요?

PC·웹에서

  1. 선물할 친구와의 DM을 열어요.
  2. 메시지 입력창 오른쪽에 있는 선물(🎁) 아이콘을 눌러요.
  3. 요금제와 기간을 고르고 다음을 눌러요.
  4. 선물 메시지를 꾸미고 싶으면 꾸미고, 선물 구매를 눌러 결제해요.
  5. 결제가 끝나면 DM에 선물 카드가 올라가요.

모바일에서

  1. 친구와의 DM을 열어요.
  2. 이번엔 입력창 왼쪽에 선물 아이콘이 있어요.
  3. 요금제를 고르고, 원하면 선물 카드 디자인이랑 메시지도 골라요.
  4. 결제하면 DM으로 바로 전달돼요.

니트로 베이직은 PC 채팅창 선물 버튼에서 안 보일 때가 있어요. 그럴 땐 사용자 설정 → Nitro 화면에서 선물로 사면 되고, 모바일은 설정 → Nitro 선물하기 메뉴를 쓰면 돼요.

선물 링크는 어떻게 보내야 안전한가요?

생각보다 자주 생기는 실수가 있어서 따로 적어요.

  • 서버 채널이나 단체 DM에 선물을 올리면 링크를 본 사람 아무나 먼저 받을 수 있어요. 한 사람한테 줄 거면 꼭 1:1 DM으로 보내세요.
  • 누가 한 번 받으면 그 선물은 다른 계정으로 못 옮겨요.
  • 아직 아무도 안 받은 선물은 사용자 설정 → 선물 인벤토리에 남아 있어요. 여기서 링크를 취소하고 새로 만들 수도 있으니, 잘못 보냈다면 바로 여기서 취소하세요.

니트로 선물은 어떻게 받나요?

DM에 온 선물 카드에서 받기 버튼을 누르면 끝이에요. 다른 사이트로 넘어가거나 비밀번호를 다시 넣을 일은 없어요.

“선물 받으려면 이 사이트에서 로그인하세요”, “QR코드 찍으면 바로 지급돼요” 같은 메시지는 무조건 사기예요. 진짜 선물은 디스코드 채팅 안에서만 받아요. 자세한 건 무료 니트로 사기 구별법에 있어요.

디스코드 니트로 구독 해지는 어떻게 하나요?

  • PC·웹: 사용자 설정(톱니바퀴) → 구독 → 니트로 배너의 취소
  • 휴대폰 앱: 내 프로필 → 톱니바퀴 → 결제 설정의 Nitro 관리 → 구독 취소
  • 아이폰 앱스토어로 결제했다면: 아이폰 설정 → 내 이름 → 구독 → Discord
  • 구글 플레이로 결제했다면: 플레이 스토어 → 프로필 → 결제 및 구독 → 구독 → Discord

앱스토어나 구글 플레이로 결제한 경우엔 디스코드 안에서 아무리 찾아도 안 끊겨요. 꼭 그 스토어에서 해지하세요.

해지는 아무 때나 할 수 있고, 해지해도 이번에 결제한 기간이 끝날 때까지는 혜택을 그대로 써요.

기간이 끝나기 전에 마음이 바뀌면 같은 화면에서 다시 구독을 누르면 돼요.

니트로를 끊으면 서버 부스트는 어떻게 되나요?

니트로에 들어 있던 부스트 2개도 같이 끝나요. 그래도 서버 레벨이 그 자리에서 바로 떨어지진 않고, 3일(72시간) 정도 여유를 줘요. 서버 레벨을 지키고 싶다면 그 안에 다른 부스트로 채워 두세요. 부스트만 따로 필요하면 디스코드 서버부스트를 보시면 돼요.

디스코드 니트로 환불은 되나요?

조건만 맞으면 돼요. 알아 둘 건 이 다섯 가지예요.

  • 기한: 니트로·서버 부스트는 구매하고 5일 안에
  • 횟수: 니트로 환불은 한 번만. 한 번 받으면 다음부터는 안 돼요
  • 선물: 아직 아무도 안 받은 선물만 환불돼요
  • 아이폰 결제: 디스코드 말고 애플 앱스토어에 요청
  • 접수하는 곳: 계정 이메일로 고객센터 결제 문의(dis.gd/billing)

선물을 환불받아도 니트로 환불 한 번을 쓴 걸로 쳐요. 나중에 정말 필요할 때 못 쓸 수 있으니 한 번 더 생각해 보고 요청하세요.

니트로를 조금이라도 싸게 쓰려면?

계속 쓸 거라면 월 구독보다 1년 구독이 싸고, 앱스토어보다는 PC·웹으로 결제하는 게 보통 더 싸요. 원하는 종류랑 기간을 말씀해 주시면 Rito0223에서 디스코드 니트로로 안내해 드릴게요. 요금제마다 뭐가 다른지는 니트로 혜택·가격 총정리에 적어 뒀어요.

자주 묻는 질문

디스코드 니트로 선물은 어떻게 해요?

친구와의 DM에서 입력창 옆 선물 아이콘을 누르고, 요금제와 기간을 골라 결제하면 DM에 선물 카드가 올라가요.

채널에 올린 니트로 선물은 누가 받아요?

링크를 본 사람 중에 먼저 누르는 사람이 가져가요. 특정 친구한테 줄 거면 1:1 DM으로 보내세요.

디스코드 니트로 해지는 어디서 해요?

PC는 사용자 설정 → 구독 탭에서 취소를 누르면 돼요. 앱스토어나 구글 플레이로 결제했다면 그 스토어의 구독 메뉴에서 해지해야 해요.

니트로를 해지하면 혜택이 바로 없어지나요?

아니요. 이번에 결제한 기간이 끝날 때까지는 혜택을 그대로 쓸 수 있어요.

디스코드 니트로 환불은 언제까지 돼요?

구매하고 5일 안에 요청할 수 있고, 니트로 환불은 한 번만 돼요. 아이폰으로 결제했다면 애플 앱스토어에 요청해야 해요.
