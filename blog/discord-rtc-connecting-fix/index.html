디스코드 RTC 연결 중·경로 없음 해결법: 음성 채널 연결이 안 되거나 끊길 때

디스코드(디코) 음성 채널에 들어가면 ‘RTC 연결 중’, ‘경로 없음’, ‘ICE 확인 중’에서 멈추거나 통화가 자꾸 끊길 때 해결하는 법을 적었어요. 원인, PC·휴대폰에서 순서대로 해볼 것, 서버 운영자가 할 수 있는 것까지 담았어요.

2026년 11월 25일 작성· Rito0223

핵심 요약

  • ‘RTC 연결 중’, ‘경로 없음’, ‘ICE 확인 중’은 대부분 내 쪽 인터넷, 방화벽, VPN이 음성 연결을 막아서 생겨요.
  • 먼저 디스코드 상태 페이지(discordstatus.com)에서 장애인지 보고, 공유기와 PC를 껐다 켜 보세요.
  • VPN을 끄고, 방화벽·백신에서 디스코드를 허용하고, 음성 설정의 QoS를 꺼 보세요.
  • ‘엔드포인트 대기 중’은 디스코드 서버 쪽 문제일 때가 많아서, 기다리거나 음성 채널 지역을 바꿔 보면 돼요.

음성 채널을 눌렀는데 왼쪽 아래에 ‘RTC 연결 중’만 계속 떠 있고 아무 소리도 안 나는 경우가 있어요. 친구들은 다 들어가 있는데 나만 못 들어가면 정말 답답하죠.

이 문제는 마이크 문제가 아니라 연결 문제예요. 원인과 해결 순서를 차례로 적어 볼게요.

RTC 연결 중, 경로 없음은 무슨 뜻인가요?

디스코드는 음성과 화면공유를 실시간 연결(RTC)로 주고받아요. 음성 채널에 들어갈 때 이 연결을 만드는 중이라는 뜻이고, 몇 초 안에 끝나야 정상이에요. 계속 멈춰 있으면 중간에서 무언가 막고 있는 거예요.

  • RTC 연결 중 / 연결 중: 음성 서버와 연결을 만드는 중에 멈춤
  • ICE 확인 중: 연결할 길을 찾는 중에 멈춤
  • 경로 없음(No Route): 연결할 길을 못 찾음
  • 엔드포인트 대기 중: 디스코드 음성 서버 응답을 기다리는 중

디스코드 공식 안내로는 앞의 세 가지는 대부분 방화벽이나 VPN처럼 내 쪽 연결을 방해하는 것 때문이고, 엔드포인트 대기 중은 디스코드 서버에 문제가 있을 때 드물게 나와요.

가장 먼저 해볼 것

  1. 디스코드 장애 확인: discordstatus.com 에 음성 장애가 표시돼 있으면 내 문제가 아니에요. 기다리면 돼요.
  2. 나갔다 다시 들어가기: 음성 채널을 나갔다가 다시 누르거나, 다른 음성 채널에 들어가 보세요.
  3. 공유기·PC 재시작: 공유기 전원을 30초쯤 뺐다 꽂고, 디스코드도 완전히 종료한 뒤 다시 켜요.
  4. 다른 인터넷으로 시험: 휴대폰 데이터로 핫스팟을 켜서 연결해 보세요. 그걸로 되면 원래 인터넷(공유기·학교·회사 와이파이) 쪽 문제예요.

PC에서 계속 안 될 때 해볼 것

  • VPN 끄기: VPN을 쓰는 중이면 꺼 보세요. 꼭 써야 한다면 UDP를 지원하는 VPN이어야 디스코드 음성이 잘 돼요
  • 방화벽·백신 허용: Windows 방화벽이나 백신 프로그램에서 Discord를 허용 목록에 넣어요
  • QoS 끄기: 사용자 설정 → 음성 및 비디오 → ‘서비스 품질 높은 패킷 우선순위 사용(QoS)’을 끄고 디스코드를 다시 켜요
  • DNS 바꾸기: 네트워크 설정에서 DNS를 구글(8.8.8.8)이나 클라우드플레어(1.1.1.1)로 바꿔 보세요
  • 네트워크 기록 초기화: 명령 프롬프트를 관리자 권한으로 열고 ipconfig /flushdns 를 입력해요
  • 웹 버전으로 시험: 브라우저에서 discord.com/app 으로 들어가 음성 채널에 붙어 보세요. 웹에서 되면 PC 앱 설정 문제일 가능성이 커요

학교, 회사, 기숙사, PC방 와이파이는 관리 정책으로 디스코드 음성을 막아 두는 경우가 있어요. 이럴 땐 설정을 아무리 바꿔도 안 되니 휴대폰 데이터로 연결하는 게 가장 빨라요.

휴대폰에서 안 될 때는?

  • 와이파이 ↔ 데이터 바꿔 보기: 한쪽에서만 안 되면 그 인터넷 문제예요
  • 앱 업데이트·재시작: 앱을 완전히 종료하고 스토어에서 업데이트가 있는지 확인해요
  • 절전 모드 끄기: 배터리 절약 모드가 백그라운드 연결을 끊는 경우가 있어요
  • VPN 앱 끄기: 휴대폰에 VPN이나 광고 차단 앱이 켜져 있으면 꺼 보세요

통화 중에 자꾸 끊길 때는?

들어가지긴 하는데 중간에 소리가 끊기거나 다시 ‘RTC 연결 중’으로 돌아간다면 인터넷이 불안정하다는 신호예요. 유선 연결로 바꾸거나, 같은 인터넷으로 다운로드·스트리밍을 하는 기기가 있는지 확인해 보세요. 소리 자체가 안 들리는 문제라면 디스코드 마이크·소리 해결법을 보세요.

서버 운영자가 할 수 있는 것

한 음성 채널에서만 여러 명이 연결이 안 되면, 그 채널의 음성 지역을 바꿔 보세요. 음성 채널 편집 → 개요에서 지역 재정의를 자동 대신 가까운 지역으로 바꾸면 연결이 바로 잡히는 경우가 있어요. 엔드포인트 대기 중이 오래 갈 때도 같은 방법이 도움이 돼요.

음성 채널 구성이나 권한이 복잡하게 꼬여 있다면 디스코드 채널 만들기를 참고하거나, 디스코드 서버제작으로 정리를 맡기셔도 돼요. 디스코드 앱 자체가 안 켜진다면 디스코드 안 켜질 때 해결법이 맞아요.

자주 묻는 질문

디스코드 RTC 연결 중은 왜 떠요?

음성 서버와 실시간 연결을 만드는 중이라는 뜻이에요. 계속 멈춰 있으면 대부분 내 쪽 인터넷, 방화벽, VPN이 연결을 막고 있는 거예요.

디스코드 경로 없음(No Route)은 어떻게 해결해요?

VPN을 끄고, 방화벽·백신에서 디스코드를 허용하고, 공유기를 재시작해 보세요. 휴대폰 데이터 핫스팟으로 연결해서 되면 원래 인터넷 쪽 문제예요.

엔드포인트 대기 중은 뭐예요?

디스코드 음성 서버 응답을 기다리는 상태로, 디스코드 쪽 문제일 때가 많아요. discordstatus.com을 확인하고, 서버 운영자라면 음성 채널의 지역 재정의를 바꿔 보세요.

디스코드 QoS는 어디서 꺼요?

사용자 설정 → 음성 및 비디오에서 '서비스 품질 높은 패킷 우선순위 사용'을 끄고 디스코드를 다시 켜면 돼요.

학교나 회사 와이파이에서만 음성이 안 돼요.

관리 정책으로 디스코드 음성을 막아 둔 경우가 많아요. 휴대폰 데이터로 연결하면 대부분 해결돼요.
