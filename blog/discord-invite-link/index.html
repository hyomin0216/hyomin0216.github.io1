디스코드 초대 링크 만들기: 만료 안 되는 링크와 초대가 안 될 때 해결법

디스코드(디코) 서버 초대 링크 만드는 법을 PC·모바일로 적었어요. 만료 기간·사용 횟수 설정, 만료 안 되는 링크 만드는 조건, 커스텀 초대 링크(discord.gg/내이름), 초대 링크가 안 될 때 확인할 것까지 담았어요.

2026년 11월 10일 작성· Rito0223

핵심 요약

  • 채널 이름 옆 사람 모양 아이콘(초대 만들기)을 누르면 링크가 바로 만들어져요. 기본은 7일 뒤 만료예요.
  • 링크 편집에서 만료 기간과 사용 횟수를 바꿀 수 있어요. 일반 서버는 최대 30일이고, 만료 없는 링크는 커뮤니티 서버여야 만들 수 있어요.
  • discord.gg/내이름 같은 커스텀 링크는 서버 부스트 레벨 3 혜택이에요.
  • 링크가 안 되면 만료됐는지, 사용 횟수가 다 찼는지, 초대가 일시 중지됐는지부터 보세요.

서버를 만들고 나서 제일 먼저 하는 게 친구 초대죠. 그런데 링크를 뿌려 놨더니 일주일 뒤에 “초대가 만료됐대요”라는 말을 듣는 경우가 많아요. 기본 설정이 7일이라서 그래요.

초대 링크 만드는 법부터, 오래 쓰는 링크 만드는 법, 안 될 때 확인할 것까지 차례로 적어 볼게요.

디스코드 초대 링크는 어떻게 만드나요?

PC·웹에서

  1. 초대할 서버에 들어가요.
  2. 채널 이름에 마우스를 올리면 오른쪽에 사람 모양 아이콘(초대 만들기)이 보여요. 이걸 눌러요.
  3. 뜨는 창에서 친구한테 바로 보내거나, 아래 링크를 복사해서 아무 데나 붙여 넣으면 돼요.

서버 이름을 눌러 메뉴를 열고 초대하기를 눌러도 같은 창이 떠요.

휴대폰에서

  1. 서버 이름을 눌러요.
  2. 초대 버튼을 누르면 링크 복사와 공유 버튼이 나와요.

초대 링크 만료 기간은 어떻게 바꾸나요?

초대 창 아래쪽 초대 링크 편집을 누르면 두 가지를 바꿀 수 있어요.

  • 만료 기간: 30분부터 고를 수 있고, 일반 서버는 최대 30일까지예요
  • 최대 사용 횟수: 1회, 5회, 10회처럼 정하거나 제한 없음으로 둘 수 있어요

아무것도 안 바꾸면 7일 뒤에 만료돼요. 한 번 바꿔 두면 그 채널에서 다음에 만드는 링크도 같은 설정을 따라가요.

임시 멤버십 부여를 켜면, 링크로 들어온 사람은 역할을 받기 전에 접속을 끊으면 서버에서 자동으로 나가져요. 행사나 일회성 모임에 쓰는 기능이라 평소에는 꺼 두세요.

만료 안 되는 초대 링크는 못 만드나요?

만들 수 있어요. 다만 서버가 커뮤니티 서버여야 해요. 일반 친구 서버는 최대 30일까지만 고를 수 있어요.

커뮤니티 서버는 서버 설정 → 커뮤니티 활성화에서 켜요. 켜려면 인증된 이메일 같은 보안 수준 설정과 규칙 채널, 공지 채널이 있어야 해서, 서버 구조가 어느 정도 잡혀 있어야 해요.

블로그, 인스타 프로필, 유튜브 설명란처럼 한 번 걸어 두고 오래 쓰는 곳에는 꼭 만료 없는 링크를 쓰세요. 7일짜리를 걸어 두면 그 뒤로 들어오는 사람이 다 막혀요.

discord.gg/내이름 같은 링크는 어떻게 만드나요?

커스텀 초대 링크라고 하는데, 서버 부스트 레벨 3(부스트 14개)부터 쓸 수 있어요. 서버 설정에서 원하는 주소를 정하면 discord.gg 뒤에 서버 이름을 붙인 링크가 생겨요.

부스트가 빠져서 레벨 3 아래로 내려가면 72시간 뒤 이 주소가 풀리고, 다른 서버가 가져갈 수도 있어요. 레벨을 올리는 방법은 서버 부스트 하는 법과 디스코드 서버부스트에 정리해 뒀어요.

초대 링크가 안 될 때는 뭘 확인하나요?

“초대가 유효하지 않아요”가 뜨면 보통 아래 중 하나예요.

  • 만료: 기간이 지났어요. 새로 만들면 돼요
  • 사용 횟수 다 참: 정해 둔 횟수만큼 이미 들어왔어요
  • 삭제됨: 관리자가 서버 설정 → 초대에서 지웠어요. 지운 링크는 같은 주소로 다시 못 살려요
  • 초대 일시 중지: 관리자가 서버 초대를 잠깐 막아 둔 상태예요
  • 차단됨: 들어가려는 사람이 그 서버에서 차단당했으면 링크가 맞아도 못 들어가요
  • 서버 수 꽉 참: 들어가려는 사람이 이미 서버 100개(니트로는 200개)에 들어가 있어요

초대 링크를 아무나 만들 수 있게 열어 두면, 모르는 사람이 링크를 퍼뜨려 테러 계정이 몰려올 수 있어요. 초대 만들기 권한은 운영진만 갖게 해 두는 게 안전해요. (서버 테러 막는 보안 설정)

초대받은 사람이 잘 정착하게 하려면?

링크로 들어온 사람이 첫 화면에서 길을 잃으면 바로 나가요. 규칙 채널, 공지, 역할 받기 채널이 눈에 잘 띄게 정리돼 있으면 남는 사람이 확 늘어요. 처음부터 구조를 잡기 어렵다면 디스코드 서버제작으로 한 번에 맡기셔도 돼요.

자주 묻는 질문

디스코드 초대 링크는 어떻게 만들어요?

채널 이름 옆 사람 모양 아이콘(초대 만들기)을 누르거나, 서버 이름 메뉴에서 초대하기를 누르면 링크가 만들어져요.

디스코드 초대 링크는 며칠 뒤에 만료돼요?

기본은 7일이에요. 초대 링크 편집에서 30분부터 최대 30일까지 바꿀 수 있어요.

만료 안 되는 초대 링크는 어떻게 만들어요?

서버를 커뮤니티 서버로 바꾸면 만료 기간에서 '만료 없음'을 고를 수 있어요. 일반 서버는 최대 30일까지예요.

discord.gg/서버이름 같은 링크는 어떻게 만들어요?

커스텀 초대 링크는 서버 부스트 레벨 3(부스트 14개)부터 쓸 수 있어요. 서버 설정에서 원하는 주소를 정하면 돼요.

초대 링크가 유효하지 않다고 나와요.

링크가 만료됐거나, 사용 횟수가 다 찼거나, 관리자가 삭제·일시 중지했을 수 있어요. 들어가려는 사람이 그 서버에서 차단됐거나 서버 100개가 꽉 찬 경우에도 못 들어가요.
