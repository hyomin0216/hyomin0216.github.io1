디스코드 사용법

디스코드 번역하는 법: 외국어 메시지 번역하기와 디스코드 한국어 설정

디스코드(디코)에서 외국어 메시지를 번역하는 방법을 적었어요. 기본 번역 버튼이 없는 이유, 번역 앱(봇) 쓰는 법, 웹 버전 브라우저 번역, 휴대폰에서 번역하는 법, 디스코드 화면을 한국어로 바꾸는 법까지 담았어요.

2026년 11월 22일 작성· Rito0223

핵심 요약

  • 디스코드에는 메시지를 번역해 주는 기본 버튼이 없어요. 번역 앱(봇)을 넣거나 다른 번역기를 같이 써야 해요.
  • 앱 디렉터리에서 ‘translate’를 검색하면 번역 앱이 나와요. 내 계정에 추가하면 서버 관리자가 아니어도 메시지 메뉴에서 번역할 수 있어요.
  • 웹 버전(discord.com/app)을 크롬으로 열면 브라우저 번역 기능으로 화면 전체를 번역할 수 있어요.
  • 디스코드 화면을 한국어로 바꾸려면 사용자 설정 → 언어에서 한국어를 고르면 돼요.

해외 게임 서버에 들어가거나 외국인 친구가 생기면 영어, 일본어 메시지가 쏟아져요. 그런데 디스코드를 아무리 뒤져도 번역 버튼은 안 보이죠.

맞아요, 디스코드에는 기본 번역 기능이 없어요. 대신 몇 가지 방법으로 꽤 편하게 번역할 수 있어요.

디스코드에 번역 기능이 있나요?

메시지 메뉴에 번역 버튼이 따로 없고, 채널을 자동으로 번역해 주는 설정도 없어요. 그래서 대부분은 아래 세 가지 중 하나를 써요.

  • 번역 앱(봇): 디스코드 안에서 바로 번역돼서 제일 편해요
  • 브라우저 번역: PC에서 웹 버전으로 쓸 때 화면 전체를 번역해요
  • 휴대폰 번역기: 메시지를 복사해서 파파고나 구글 번역에 붙여 넣어요

번역 앱(봇)은 어떻게 쓰나요?

디스코드 앱 디렉터리에는 번역 앱이 여러 개 있어요. 쓰는 방법은 두 가지예요.

내 계정에 추가하기 (관리자가 아니어도 돼요)

  1. 앱 디렉터리에서 “translate”를 검색해요.
  2. 번역 앱을 골라 앱 추가 → 내 앱에 추가를 눌러요.
  3. 번역하고 싶은 메시지를 우클릭(휴대폰은 길게 누르기)하고 앱에서 번역을 골라요.
  4. 번역 결과는 보통 나한테만 보여요.

서버에 추가하기 (서버 관리자)

서버에 번역 앱을 넣으면 멤버 모두가 쓸 수 있어요. 국기 이모지로 반응을 달면 그 나라 말로 번역해 주거나, 특정 채널 메시지를 자동으로 번역해 주는 앱도 있어요. 서버에 앱 넣는 법은 디스코드 봇 추가하는 법에 있어요.

번역 앱은 대부분 기본 기능은 무료이고, 긴 글이나 자동 번역은 유료인 경우가 많아요. 권한은 메시지 읽기·보내기 정도면 충분해요. 관리자 권한을 달라는 번역 앱은 피하세요.

PC에서 화면 전체를 번역하려면?

크롬이나 엣지에서 discord.com/app으로 웹 버전에 들어가요. 주소창 오른쪽 번역 아이콘(또는 화면 우클릭 → 한국어로 번역)을 누르면 채팅이 통째로 번역돼요. 버튼 글자까지 같이 바뀌어서 조금 어색할 수 있지만, 대화 흐름을 따라가기엔 충분해요. 웹 버전 쓰는 법은 디스코드 웹 버전 사용법에 있어요.

휴대폰에서는 어떻게 번역하나요?

  1. 번역할 메시지를 길게 눌러요.
  2. 텍스트 복사를 눌러요.
  3. 파파고나 구글 번역 앱에 붙여 넣어요.

내 계정에 번역 앱을 추가해 뒀다면 휴대폰에서도 메시지를 길게 눌러 앱 메뉴에서 바로 번역할 수 있어요.

디스코드 앱을 개조하는 프로그램에 번역 기능을 붙여 쓰는 방법도 돌아다니는데, 디스코드 이용약관에 어긋나고 계정이 털릴 위험도 있어요. 공식 앱 디렉터리에 있는 앱을 쓰세요. (디스코드 계정 보안)

디스코드 화면을 한국어로 바꾸려면?

메뉴가 영어로 나온다면 언어 설정만 바꾸면 돼요.

  • PC·웹: 사용자 설정(톱니바퀴) → 언어(Language) → 한국어
  • 휴대폰: 화면 아래 내 프로필 → 오른쪽 위 톱니바퀴 → 언어(Language) → 한국어

이건 디스코드 메뉴 글자만 바꾸는 거라서, 다른 사람이 쓴 메시지는 번역되지 않아요.

외국인 멤버가 많은 서버를 운영한다면

  • 언어별 채널: 한국어 채팅, English chat처럼 채널을 나눠요
  • 언어 역할: 들어올 때 언어 역할을 고르게 하고, 그 역할만 해당 채널이 보이게 해요
  • 자동 번역 채널: 번역 앱으로 공지 채널만 자동 번역하면 공지를 두 번 쓸 필요가 없어요

역할로 채널을 나누는 법은 디스코드 역할·권한 설정에 있어요. 다국어 서버 구조를 처음부터 잡고 싶다면 디스코드 서버제작으로 맡기셔도 돼요.

자주 묻는 질문

디스코드에 번역 기능이 있나요?

디스코드에는 메시지를 번역해 주는 기본 버튼이 없어요. 번역 앱(봇)을 추가하거나, 웹 버전에서 브라우저 번역을 쓰거나, 메시지를 복사해서 번역기에 붙여 넣어야 해요.

서버 관리자가 아니어도 번역 앱을 쓸 수 있어요?

네. 번역 앱을 '내 앱에 추가'로 내 계정에 넣으면, 메시지를 우클릭하거나 길게 눌러 앱 메뉴에서 번역할 수 있어요.

디스코드 채팅을 통째로 번역할 수 있어요?

PC에서 웹 버전(discord.com/app)을 크롬이나 엣지로 열고 브라우저 번역을 켜면 화면 전체가 번역돼요.

디스코드를 한국어로 바꾸려면 어떻게 해요?

사용자 설정 → 언어(Language)에서 한국어를 고르면 돼요. 휴대폰은 화면 아래 내 프로필 → 톱니바퀴 → 언어에서 바꿔요.

휴대폰에서는 어떻게 번역해요?

메시지를 길게 눌러 텍스트를 복사한 뒤 파파고나 구글 번역에 붙여 넣으면 돼요. 내 계정에 번역 앱을 추가했다면 앱 메뉴에서 바로 번역할 수 있어요.
