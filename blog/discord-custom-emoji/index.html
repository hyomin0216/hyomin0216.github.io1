디스코드 이모지 추가하는 법: 서버 이모지 만들기와 개수 늘리기

디스코드(디코) 서버에 이모지 추가하는 법을 PC·모바일로 적었어요. 이미지 조건(256KB, 이름 규칙), 기본 50개에서 부스트로 250개까지 늘리는 법, 다른 서버에서 이모지 쓰는 법까지 담았어요.

2026년 11월 10일 작성· 약 3분· Rito0223

핵심 요약

  • 서버 설정 → 이모지 → 이모지 업로드에서 추가해요. 서버 주인이나 이모지 관리 권한이 있어야 해요.
  • 이미지는 256KB 이하 PNG·JPG·GIF·WEBP이고, 이름은 영어·숫자·밑줄로 2글자 이상이어야 해요.
  • 기본은 일반 50개 + 움직이는 이모지 50개예요. 부스트 레벨 1은 100개, 2는 150개, 3은 250개씩으로 늘어나요.
  • 서버 이모지는 그 서버에서만 쓸 수 있고, 다른 서버에서도 쓰려면 니트로나 니트로 베이직이 필요해요.

서버 분위기를 제일 빨리 바꾸는 게 이모지예요. 우리 서버만의 이모지가 몇 개만 있어도 채팅이 확 살아나요. 그런데 몇 개 올리다 보면 금방 “칸이 꽉 찼어요”가 떠요.

이모지 올리는 법, 안 올라갈 때 확인할 것, 칸 늘리는 법까지 적어 볼게요.

디스코드 서버 이모지는 어떻게 추가하나요?

PC·웹에서

  1. 서버 이름을 눌러 서버 설정으로 들어가요.
  2. 왼쪽 메뉴에서 이모지를 눌러요.
  3. 이모지 업로드를 누르고 이미지를 골라요.
  4. 올라간 이모지 이름을 원하는 대로 바꾸면 끝이에요. 채팅에서 :이름: 으로 불러 쓸 수 있어요.

휴대폰에서

  1. 서버 이름을 누르고 설정으로 들어가요.
  2. 이모지 → 이모지 업로드를 누르고 사진을 골라요.
  3. 잘라낼 영역을 맞추고 이름을 정하면 돼요.

이모지를 올리려면 서버 주인이거나 이모지 관리(표현 관리) 권한이 있는 역할이어야 해요. 메뉴가 안 보이면 권한이 없는 거예요.

이모지가 안 올라갈 때는?

  • 용량: 256KB를 넘으면 안 올라가요. 움직이는 GIF가 자주 걸려요
  • 파일 형식: PNG, JPG, GIF, WEBP만 돼요
  • 이름: 영어, 숫자, 밑줄(_)만 쓸 수 있고 2글자 이상이어야 해요. 한글 이름은 안 돼요
  • 칸 부족: 이미 꽉 찼으면 안 쓰는 이모지를 지우거나 칸을 늘려야 해요

이모지는 작게 보여서 128×128 정도 정사각형으로 만들고, 배경을 투명하게 빼면 제일 깔끔해요. 글자를 넣을 땐 두껍게 써야 작은 크기에서도 읽혀요.

이모지는 몇 개까지 올릴 수 있나요?

일반 이모지와 움직이는 이모지 칸이 따로 있고, 서버 부스트 레벨에 따라 늘어나요.

  • 부스트 없음: 일반 50개 + 움직이는 50개
  • 레벨 1 (부스트 2개): 각각 100개, 스티커 15개
  • 레벨 2 (부스트 7개): 각각 150개, 스티커 30개
  • 레벨 3 (부스트 14개): 각각 250개, 스티커 60개

부스트가 빠져서 레벨이 내려가도 72시간 동안은 그대로예요. 그 뒤엔 넘치는 이모지가 잠깐 못 쓰는 상태가 되고, 지워지지는 않아요. 다시 레벨을 채우면 돌아와요.

칸을 늘리는 방법은 서버 부스트 하는 법에 있고, 부스트가 필요하면 디스코드 서버부스트에서 레벨별로 문의하실 수 있어요.

다른 서버에서도 우리 서버 이모지를 쓸 수 있나요?

서버 이모지는 원래 그 서버 안에서만 쓸 수 있어요. 니트로나 니트로 베이직이 있으면 내가 들어가 있는 서버의 이모지를 다른 서버나 DM에서도 쓸 수 있어요. 니트로 혜택은 니트로 혜택·가격 총정리에 정리해 뒀어요.

이모지 말고 서버를 더 꾸미고 싶다면

채널 이름에 이모지와 특수문자를 섞으면 서버가 한결 정돈돼 보여요. 디스코드 채널명 꾸미기에 바로 쓸 수 있는 예시를 모아 뒀어요. 서버 전체 디자인을 맞추고 싶다면 디스코드 서버제작도 있어요.

자주 묻는 질문

디스코드 이모지는 어디서 추가해요?

서버 설정 → 이모지 → 이모지 업로드에서 추가할 수 있어요. 서버 주인이나 이모지 관리 권한이 있는 사람만 올릴 수 있어요.

디스코드 이모지 용량 제한은 얼마예요?

256KB 이하여야 하고, PNG·JPG·GIF·WEBP 파일만 올라가요.

디스코드 이모지 이름을 한글로 할 수 있어요?

안 돼요. 영어, 숫자, 밑줄(_)만 쓸 수 있고 2글자 이상이어야 해요.

디스코드 서버 이모지는 몇 개까지 돼요?

기본은 일반 50개와 움직이는 이모지 50개예요. 서버 부스트 레벨 1은 100개, 레벨 2는 150개, 레벨 3은 250개씩으로 늘어나요.

다른 서버 이모지를 쓰려면 어떻게 해요?

니트로나 니트로 베이직이 있으면 내가 들어가 있는 서버의 이모지를 다른 서버와 DM에서도 쓸 수 있어요.
