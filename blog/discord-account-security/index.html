디스코드 계정 보안: 비밀번호 변경, 2단계 인증, 해킹 당했을 때 할 일

디스코드(디코) 계정을 지키는 법을 적었어요. 비밀번호 바꾸는 곳, 2단계 인증 켜는 법과 백업 코드, 로그인된 기기 정리, 계정이 해킹됐을 때 순서대로 할 일까지 담았어요.

2026년 11월 10일 작성· 약 3분· Rito0223

핵심 요약

  • 비밀번호는 사용자 설정 → 내 계정 → 비밀번호 변경에서 바꿔요.
  • 같은 화면에서 인증 앱으로 2단계 인증을 켜고, 백업 코드는 꼭 따로 저장해 두세요.
  • 사용자 설정 → 기기에서 모르는 기기를 로그아웃시킬 수 있어요.
  • 해킹이 의심되면 비밀번호 변경 → 2단계 인증 → 기기 로그아웃 → 연결된 앱 정리 순서로 바로 움직이세요.

디스코드 계정이 털리면 내 계정만 문제가 아니에요. 내 이름으로 친구들한테 사기 링크가 뿌려지고, 내가 관리자인 서버가 통째로 날아가기도 해요. 서버를 운영하는 분이라면 더 신경 써야 하는 부분이에요.

평소에 해 둘 것과, 이미 당했을 때 할 일을 나눠서 적어 볼게요.

디스코드 비밀번호는 어디서 바꾸나요?

  • PC·웹: 왼쪽 아래 톱니바퀴(사용자 설정) → 내 계정 → 비밀번호 변경
  • 휴대폰: 오른쪽 아래 내 프로필 → 톱니바퀴 → 계정 → 비밀번호

다른 사이트에서 쓰던 비밀번호를 그대로 쓰지 마세요. 다른 곳에서 새면 디스코드도 같이 뚫려요.

비밀번호를 잊어버렸다면

로그인 화면에서 이메일을 넣고 비밀번호를 잊으셨나요?를 누르면 재설정 메일이 와요. 안 보이면 스팸함을 확인하세요.

2단계 인증은 어떻게 켜나요?

2단계 인증을 켜 두면 비밀번호가 새도 내 휴대폰 없이는 로그인이 안 돼요. 계정 보안에서 가장 효과가 큰 설정이에요.

  1. 휴대폰에 인증 앱을 깔아요. Google Authenticator나 Authy 같은 앱이에요.
  2. 디스코드 사용자 설정 → 내 계정 → 2단계 인증 활성화를 눌러요.
  3. 화면에 뜬 QR코드를 인증 앱으로 찍어요.
  4. 인증 앱에 나온 6자리 숫자를 디스코드에 입력하면 끝이에요.

켜고 나면 백업 코드를 꼭 내려받아 두세요. 휴대폰을 잃어버리거나 바꿨을 때 이 코드가 없으면 계정에 다시 들어가기가 아주 어려워져요. 휴대폰 말고 다른 곳(메모장 파일, 종이)에 보관하세요.

문자 인증을 백업 수단으로 추가할 수도 있어요. 다만 문자는 인증 앱보다 약해서, 인증 앱을 기본으로 쓰는 게 좋아요.

내 계정에 로그인된 기기는 어떻게 확인하나요?

사용자 설정 → 기기에 들어가면 지금 로그인된 컴퓨터와 휴대폰이 다 나와요. 모르는 기기가 있으면 그 기기만 로그아웃시키거나, 다른 모든 기기에서 로그아웃으로 한 번에 정리할 수 있어요.

디스코드 계정이 해킹된 것 같으면 뭐부터 하나요?

내가 안 보낸 메시지가 친구들한테 가 있거나, 모르는 서버에 들어가 있으면 바로 아래 순서로 하세요.

  1. 비밀번호부터 바꿔요. 비밀번호를 바꾸면 다른 기기에 로그인된 상태도 풀려요.
  2. 2단계 인증을 켜요. 이미 켜져 있었다면 백업 코드도 새로 받아 두세요.
  3. 기기 목록을 정리해요. 사용자 설정 → 기기에서 모르는 기기를 모두 로그아웃시켜요.
  4. 연결된 앱을 확인해요. 사용자 설정 → 승인된 앱에서 모르는 앱이나 봇은 승인을 취소해요.
  5. 친구들한테 알려요. 내 계정으로 온 링크는 누르지 말라고 말해 두세요.

이메일까지 바뀌어서 로그인 자체가 안 되면 혼자서는 되돌리기 어려워요. 디스코드 고객센터(support.discord.com)에 원래 이메일로 문의해야 해요. 이메일 계정 비밀번호도 같이 바꿔 두세요.

해킹은 보통 어떻게 당하나요?

  • 가짜 무료 니트로 링크: 디스코드처럼 생긴 사이트에서 로그인하게 만들어요
  • QR코드 스캔 요청: “인증하려면 이 QR을 찍어 주세요” 하고 내 휴대폰으로 로그인을 승인하게 만들어요
  • 게임·프로그램 테스트 부탁: 친구 계정으로 “내가 만든 게임 해 봐” 하며 파일을 받게 해요
  • 가짜 디스코드 직원: 디스코드는 DM으로 비밀번호나 인증 코드를 절대 묻지 않아요

가장 흔한 무료 니트로 수법은 무료 니트로 사기 구별법에 자세히 적어 뒀어요.

서버 운영자라면 이것까지 해 두세요

관리자 계정 하나가 털리면 채널 삭제, 멤버 추방까지 한 번에 당할 수 있어요. 운영진 전원 2단계 인증을 켜고, 서버 설정 → 안전 설정에서 관리 작업에 2단계 인증 필수를 켜 두면 2단계 인증이 없는 계정은 관리 기능을 못 써요. 서버 보안 전체는 서버 테러 막는 보안 설정에 정리해 뒀어요.

자주 묻는 질문

디스코드 비밀번호는 어디서 바꿔요?

PC는 사용자 설정 → 내 계정 → 비밀번호 변경, 휴대폰은 내 프로필 → 톱니바퀴 → 계정 → 비밀번호에서 바꿀 수 있어요.

디스코드 2단계 인증은 어떻게 켜요?

인증 앱을 설치한 뒤 사용자 설정 → 내 계정 → 2단계 인증 활성화에서 QR코드를 찍고, 앱에 나온 6자리 숫자를 입력하면 돼요.

2단계 인증 휴대폰을 잃어버렸어요.

켤 때 받아 둔 백업 코드로 로그인할 수 있어요. 문자 백업을 등록해 뒀다면 문자로도 받을 수 있어요. 둘 다 없으면 계정 복구가 어려워져요.

디스코드 계정이 해킹당하면 뭐부터 해야 해요?

비밀번호 변경, 2단계 인증 켜기, 기기 목록에서 모르는 기기 로그아웃, 승인된 앱 정리 순서로 바로 하세요. 이메일까지 바뀌었다면 디스코드 고객센터에 문의해야 해요.

로그인된 기기는 어디서 확인해요?

사용자 설정 → 기기에서 지금 로그인된 기기를 모두 보고, 모르는 기기를 로그아웃시킬 수 있어요.
