디스코드 서버 부스트 하는 법, 몇 개부터 효과가 있을까?

디스코드 서버 부스트를 PC·모바일에서 하는 방법, 레벨 1·2·3에 필요한 부스트 개수(2·7·14개), 니트로에 포함된 부스트와 할인, 부스트를 옮길 때의 7일 쿨타임까지 정리했어요.

2026년 10월 26일 작성· 약 3분· Rito0223

핵심 요약

  • 서버 이름을 누르고 ‘서버 부스트’ → ‘이 서버 부스트하기’를 누르면 바로 부스트할 수 있어요.
  • 서버 레벨은 부스트 개수로 정해져요. 레벨 1은 2개, 레벨 2는 7개, 레벨 3은 14개가 필요해요.
  • 니트로(정식) 구독에는 부스트 2개가 포함되고, 추가 부스트는 30% 할인돼요. 니트로 베이직에는 이 혜택이 없어요.
  • 부스트를 다른 서버로 옮기려면 사용 후 7일이 지나야 하고, 레벨이 내려가도 72시간 동안은 혜택이 유지돼요.

“이모지 칸이 모자라요”, “화면공유 화질을 올리고 싶어요” 같은 고민은 대부분 서버 부스트로 해결돼요. 그런데 막상 하려고 보면 어디서 누르는지, 몇 개를 해야 효과가 있는지부터 헷갈리죠.

이 글에서는 디스코드 서버 부스트를 하는 방법과 레벨별로 필요한 개수, 알아두면 손해 안 보는 규칙까지 한 번에 정리했어요.

디스코드 서버 부스트는 어떻게 하나요?

PC와 모바일 모두 순서는 같아요.

  1. 부스트하고 싶은 서버에 들어갑니다.
  2. 왼쪽 위 서버 이름을 눌러 메뉴를 엽니다.
  3. 서버 부스트를 선택합니다.
  4. 이 서버 부스트하기를 누릅니다.
  5. 쓰지 않은 부스트가 있으면 바로 적용되고, 없으면 부스트 구매 화면으로 넘어가요.

니트로(정식)를 구독 중이라면 부스트 2개가 이미 들어 있어요. 구매 화면이 뜨기 전에 남은 부스트가 있는지 먼저 확인해 보세요.

몇 개부터 효과가 있나요? 레벨별 필요 개수

서버 혜택은 부스트 개수에 따라 정해지는 서버 레벨로 열려요. 상위 레벨은 아래 레벨 혜택을 모두 포함해요.

레벨필요 부스트대표 혜택
레벨 12개커스텀 이모지 100칸, 스티커 15칸, 오디오 128kbps, 애니메이션 서버 아이콘, 화면공유 720p 60fps
레벨 27개커스텀 이모지 150칸, 스티커 30칸, 오디오 256kbps, 업로드 50MB, 서버 배너, 화면공유 1080p 60fps
레벨 314개커스텀 이모지 250칸, 스티커 60칸, 오디오 384kbps, 업로드 100MB, 커스텀 초대 링크(vanity URL), 애니메이션 서버 배너

즉 부스트 1개만으로는 레벨이 오르지 않고, 최소 2개가 모여야 레벨 1 혜택이 생겨요. 서버 배너가 목적이라면 7개, 서버 전용 주소(discord.gg/원하는이름)가 필요하다면 14개가 목표예요. 레벨별 혜택은 서버부스트 레벨별 차이 페이지에서 더 자세히 볼 수 있어요.

니트로가 있으면 부스트가 공짜인가요?

절반은 맞아요. 디스코드 공식 안내 기준으로 정리하면 이래요.

  • 니트로(정식): 부스트 2개 포함 + 추가 부스트 30% 할인
  • 니트로 베이직: 포함 부스트와 할인 없음

그래서 니트로 1명이 가진 부스트 2개를 쓰면 바로 레벨 1이 돼요. 니트로와 베이직의 다른 차이는 니트로 vs 니트로 베이직 비교에서 확인해 보세요.

부스트를 다른 서버로 옮기려면?

  1. 사용자 설정(톱니바퀴)을 엽니다.
  2. 서버 부스트 탭으로 들어갑니다.
  3. 옮길 부스트 옆의 점 3개 버튼을 누르고 부스트 이전을 선택합니다.
  4. 옮길 서버를 고르고 확인하면 끝이에요.

단, 부스트를 사용한 뒤 7일 쿨타임이 지나야 옮길 수 있어요. 부스트를 빼면 원래 서버의 레벨이 내려갈 수 있으니 운영진과 미리 이야기해 두세요.

부스트가 빠지면 혜택은 바로 사라지나요?

아니요. 부스트 수가 레벨 기준 아래로 내려가도 72시간 동안은 혜택이 유지돼요. 72시간이 지나면 서버 배너, 추가 이모지 칸 같은 혜택이 일시적으로 비활성화되고, 다시 개수를 채우면 돌아와요.

예외가 하나 있어요. 커스텀 초대 링크(vanity URL)는 72시간 뒤 해제되어 다른 서버가 그 주소를 가져갈 수 있어요. 레벨 3 주소를 쓰고 있다면 부스트 수가 떨어지지 않게 특히 신경 써야 해요.

정리

  • 부스트는 서버 이름 → 서버 부스트 → 이 서버 부스트하기
  • 레벨은 2개 / 7개 / 14개에서 올라가요
  • 니트로(정식)는 부스트 2개 포함, 베이직은 없음
  • 옮길 땐 7일 쿨타임, 빠지면 72시간 유예

혜택 수치는 디스코드 정책에 따라 바뀔 수 있어요. 목표 레벨만 정해지면 필요한 개수와 가장 빠른 방법을 함께 안내해 드려요.

자주 묻는 질문

디스코드 부스트 1개만 해도 의미가 있나요?

레벨은 부스트 2개부터 올라가기 때문에 1개만으로는 서버 레벨 혜택이 생기지 않아요. 다만 부스트한 사람에게는 서버 부스터 표시가 붙고, 다른 사람의 부스트와 합쳐져 레벨 달성에 보태져요.

니트로 베이직으로도 서버 부스트가 되나요?

디스코드 공식 안내 기준으로 니트로 베이직에는 기본 포함 부스트와 부스트 할인 혜택이 없어요. 부스트 2개 포함과 30% 할인은 니트로(정식) 구독 혜택이에요.

부스트를 다른 서버로 바로 옮길 수 있나요?

부스트를 사용한 뒤 7일 쿨타임이 지나야 옮길 수 있어요. 사용자 설정의 서버 부스트 메뉴에서 해당 부스트의 점 3개 버튼을 눌러 ‘부스트 이전’을 선택하면 돼요.

부스트가 빠져서 레벨이 내려가면 이모지가 사라지나요?

레벨 기준 아래로 내려가도 72시간 동안은 혜택이 유지돼요. 그 뒤에는 배너·추가 이모지 칸 같은 혜택이 일시적으로 비활성화되고, 다시 레벨을 채우면 돌아와요. 단, 커스텀 초대 링크는 72시간 뒤 해제되어 다른 서버가 가져갈 수 있어요.

원하는 레벨까지 한 번에 맞출 수 있나요?

네. Rito0223에 목표 레벨(1·2·3)을 알려주시면 필요한 부스트 개수와 함께 안내해 드려요. 2·3레벨은 로켓지급으로 구매하면 1시간 안에 받을 수 있어요.
