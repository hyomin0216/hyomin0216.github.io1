디스코드 사용법

디스코드 봇 추가하는 법: 노래봇·TTS봇 서버에 넣기 (PC·모바일)

디스코드(디코) 서버에 봇을 추가하는 방법을 PC·모바일로 나눠 정리했어요. 필요한 권한(서버 관리하기), 앱 디렉터리 이용법, 노래봇·TTS봇 고르는 법, 봇이 안 들어올 때 해결법까지 담았어요.

2026년 11월 3일 작성· 약 3분· Rito0223

핵심 요약

  • 봇을 서버에 넣으려면 서버 주인이거나 서버 관리하기 권한이 있어야 해요.
  • 봇의 초대 링크나 디스코드 앱 디렉터리에서 “서버에 추가”를 누르고 서버를 고르면 끝이에요.
  • 봇이 요구하는 권한은 꼭 필요한 것만 주세요. 관리자 권한은 신뢰할 수 있는 봇에만 주는 게 안전해요.
  • 봇을 넣었는데 반응이 없으면 채널 권한과 봇 역할 순서부터 확인하세요.

노래봇, TTS봇, 출석·레벨봇, 보안봇까지 디스코드 서버를 편하게 해 주는 건 대부분 봇이에요. 이 글에서는 디스코드 봇을 서버에 추가하는 방법과, 넣은 뒤 꼭 확인해야 할 설정을 정리했어요.

디스코드 봇을 추가하려면 어떤 권한이 필요한가요?

서버 주인이거나 서버 관리하기(Manage Server) 권한이 있는 역할만 봇을 추가할 수 있어요. 권한이 없으면 봇 초대 화면에서 내 서버가 목록에 아예 안 보여요.

PC에서 디스코드 봇은 어떻게 추가하나요?

방법 1. 봇 초대 링크로 추가

  1. 넣고 싶은 봇의 공식 사이트에서 초대(Invite) / 서버에 추가 버튼을 누릅니다.
  2. 디스코드 로그인 후 서버 선택 목록에서 봇을 넣을 서버를 고릅니다.
  3. 봇이 요청하는 권한 목록을 확인하고 승인을 누릅니다.
  4. 사람이 아닌지 확인(캡차)을 마치면 서버 멤버 목록에 봇이 나타나요.

방법 2. 앱 디렉터리에서 찾아서 추가

  1. 서버 이름을 눌러 메뉴를 열고 앱 디렉터리(또는 서버 설정 → 앱 → 앱 디렉터리)로 들어갑니다.
  2. “music”, “tts”처럼 원하는 기능을 검색합니다.
  3. 봇을 누르고 앱 추가 → 서버에 추가를 선택한 뒤 권한을 승인합니다.

앱 디렉터리에 있는 봇이라도 개발자는 디스코드가 아닌 다른 회사·개인이에요. 리뷰와 서버 수를 보고 고르세요.

모바일에서도 디스코드 봇을 추가할 수 있나요?

네. 휴대폰 브라우저에서 봇 초대 링크를 열면 디스코드 앱이나 웹 로그인 화면으로 이어지고, PC와 똑같이 서버 선택 → 권한 승인 순서로 진행돼요. 화면이 작아 서버 목록이 안 보이면 브라우저 메뉴의 데스크톱 사이트 보기를 켜 보세요.

봇에게 권한은 얼마나 줘야 하나요?

봇이 하는 일에 필요한 만큼만 주는 게 원칙이에요.

봇 종류보통 필요한 권한
노래봇음성 채널 연결·말하기, 메시지 보내기
TTS봇음성 채널 연결·말하기, 메시지 읽기
레벨·출석봇메시지 보내기, 역할 관리(보상 역할을 줄 때)
보안·인증봇멤버 추방·차단, 역할 관리, 메시지 관리

관리자(Administrator) 권한을 준 봇은 서버의 모든 것을 바꿀 수 있어요. 출처가 확실한 봇이 아니라면 관리자 권한은 빼고 승인하세요. (서버 테러 막는 보안 설정)

봇을 넣었는데 반응이 없을 때는 어떻게 하나요?

  • 채널 권한: 봇 역할이 그 채널에서 “채널 보기”, “메시지 보내기” 권한을 갖고 있는지 확인하세요.
  • 역할 순서: 봇이 역할을 줘야 한다면, 서버 설정 → 역할에서 봇 역할을 주려는 역할보다 위로 올려야 해요.
  • 명령어 방식: 요즘 봇은 대부분 / 를 입력하면 뜨는 슬래시 명령어를 써요. 예전 방식(!play)이 안 되면 / 로 시도해 보세요.
  • 노래봇이 조용할 때: 봇이 음성 채널에 들어왔는지, 내 쪽에서 봇 음량을 0으로 줄이지 않았는지 확인하세요.

봇 세팅이 어렵다면?

입장 인사, 역할 자동 지급, 인증, 로그(입장·메시지·통화방·역할) 같은 봇 구성은 서버마다 조합이 달라요. 처음부터 맞추기 어렵다면 Rito0223의 디스코드 서버제작으로 봇 세팅까지 한 번에 맡길 수 있어요. 직접 만들고 싶다면 디스코드 서버 만드는 법부터 보세요.

자주 묻는 질문

디스코드 봇 추가는 누구나 할 수 있나요?

아니요. 서버 주인이거나 '서버 관리하기' 권한이 있는 사람만 서버에 봇을 추가할 수 있어요.

봇 초대 화면에 내 서버가 안 보여요.

그 서버에서 '서버 관리하기' 권한이 없거나, 다른 계정으로 로그인한 경우예요. 계정과 권한을 확인해 보세요.

디스코드 노래봇은 어떻게 쓰나요?

노래봇을 서버에 추가한 뒤 음성 채널에 들어가 / 를 입력하면 나오는 재생 명령어로 노래를 틀 수 있어요. 명령어 이름은 봇마다 달라요.

모바일로도 봇을 넣을 수 있나요?

네. 휴대폰 브라우저에서 봇 초대 링크를 열고 서버 선택과 권한 승인을 하면 돼요.

봇에게 관리자 권한을 줘도 되나요?

관리자 권한을 받은 봇은 서버의 모든 설정을 바꿀 수 있어요. 출처가 확실하지 않은 봇에는 필요한 권한만 주는 게 안전해요.
