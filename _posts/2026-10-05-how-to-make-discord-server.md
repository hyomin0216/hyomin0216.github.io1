디스코드 서버는 누구나 무료로 만들 수 있어요. 문제는 **만든 다음**이에요. 채널을 아무렇게나 늘리고 권한을 대충 두면, 멤버가 30명만 넘어도 공지가 묻히고 아무나 채널을 지우는 상황이 생기거든요.

이 글에서는 처음 서버를 만드는 사람이 **어떤 순서로, 무엇을 먼저 세팅해야 하는지** 6단계로 정리했어요.

## 1단계. 서버 만들기

1. 디스코드 앱(PC·모바일 모두 가능) 왼쪽 서버 목록 맨 아래의 **+ 버튼**(서버 추가하기)을 누릅니다.
2. **직접 만들기**를 선택합니다. 템플릿(게임, 스터디 등)을 고르면 기본 채널이 자동으로 생기지만, 대부분 다시 정리하게 되니 직접 만드는 걸 추천해요.
3. "친구들을 위한 서버"인지 "클럽이나 커뮤니티를 위한 서버"인지 고릅니다. 나중에 바꿀 수 있으니 부담 갖지 않아도 돼요.
4. 서버 이름과 아이콘을 정하고 **만들기**를 누르면 끝이에요.

> 서버 아이콘은 정사각형 이미지가 가장 깔끔하게 나와요. 원형으로 잘려 보이니 가장자리에 중요한 글자를 넣지 마세요.

## 2단계. 카테고리로 채널 뼈대 잡기

채널을 만들기 전에 **카테고리**부터 정하는 게 핵심이에요. 카테고리는 채널을 묶는 폴더 같은 개념이고, 카테고리 단위로 권한을 한 번에 줄 수 있어서 관리가 훨씬 편해져요.

서버 목적별로 많이 쓰는 기본 구성은 이래요.

| 서버 목적 | 추천 카테고리 | 대표 채널 |
| --- | --- | --- |
| 친구·소규모 | 공지 / 채팅 / 음성 | 공지, 자유채팅, 짤방, 일반 음성 |
| 게임 커뮤니티 | 안내 / 커뮤니티 / 게임별 / 음성 | 규칙, 공지, 파티모집, 게임별 채팅, 게임별 음성 |
| 스터디 | 안내 / 스터디 / 자료 / 음성 | 규칙, 출석체크, 질문, 자료공유, 캠스터디 |
| 판매·브랜드 | 안내 / 상품 / 고객센터 | 공지, 상품안내, 후기, 문의 |

처음부터 채널을 많이 만들 필요는 없어요. **조용한 채널이 많으면 서버가 비어 보이기 때문에**, 최소 구성으로 시작해서 늘려가는 게 좋아요.

## 3단계. 역할(Role) 만들기

역할은 멤버에게 붙이는 "직급"이에요. 서버 이름 → **서버 설정 → 역할 → 역할 만들기**에서 추가할 수 있어요.

보통 이 정도면 충분해요.

- **관리자**: 서버 전체 관리 (믿을 수 있는 1~2명만)
- **운영진**: 메시지 관리, 멤버 타임아웃 등 일상 관리
- **멤버**: 인증을 마친 일반 멤버
- **봇**: 봇 전용 역할 (봇을 넣으면 자동으로 생기는 경우가 많아요)

역할 목록은 **위에 있을수록 높은 권한**을 가져요. 운영진 역할이 관리자 역할보다 위에 있으면 안 되니 순서를 꼭 확인하세요.

## 4단계. 권한 설정 — 가장 많이 실수하는 부분

디스코드 권한은 두 단계로 적용돼요.

1. **역할 권한**: 서버 전체에 적용되는 기본 권한
2. **채널(카테고리) 권한**: 특정 채널에서만 덮어쓰는 권한

안전하게 세팅하는 원칙은 하나예요. **@everyone(모든 사람) 역할은 최소한으로, 필요한 역할에만 열어주기.**

- 공지 채널: @everyone은 **메시지 보내기 끄기**, 운영진만 켜기
- 운영진 전용 채널: @everyone은 **채널 보기 끄기**, 운영진만 켜기
- 인증 전용 구조: @everyone은 인증 채널만 보이게 하고, 인증 후 **멤버** 역할을 받으면 나머지 채널이 열리게

> "관리자(Administrator)" 권한은 모든 권한을 무시하고 전부 허용해요. 봇이나 여러 사람에게 주지 말고 꼭 필요한 사람에게만 주세요.

## 5단계. 봇 연동

봇은 환영 메시지, 자동 역할 부여, 레벨 시스템, 스팸 차단 같은 반복 작업을 맡아줘요. 봇마다 공식 사이트에서 **초대하기 → 서버 선택 → 권한 승인** 순서로 추가하면 돼요.

봇을 넣을 때 주의할 점은 두 가지예요.

- 봇이 요구하는 권한을 **그대로 다 주지 말고**, 기능에 필요한 권한만 남기세요.
- 봇 역할이 자동 부여할 역할보다 **위에 있어야** 역할 지급이 정상 작동해요.

## 6단계. 커뮤니티 기능 켜기 (공개 서버라면)

모르는 사람도 들어오는 서버라면 **서버 설정 → 커뮤니티 활성화**를 추천해요. 켜면 규칙 채널과 공지 채널을 지정할 수 있고, 환영 화면·온보딩 같은 커뮤니티 전용 기능을 쓸 수 있어요.

함께 해두면 좋은 안전 설정도 있어요.

- 인증 레벨 올리기 (이메일 인증된 계정만 채팅 가능 등)
- 부적절한 미디어 자동 필터 켜기
- 규칙 채널에 서버 규칙 고정해 두기

## 마무리

여기까지가 기본이지만, 실제로는 **권한 충돌, 봇 설정, 배너·이모지 디자인**에서 시간이 가장 많이 들어요. 서버 목적만 알려주시면 채널 구조부터 권한·봇·디자인까지 한 번에 세팅해 드려요. 이모지 칸이나 화질이 더 필요하다면 [서버부스트 레벨별 혜택](/discord-server-boost/)도 함께 확인해 보세요.
